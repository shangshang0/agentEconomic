# Evidence tiers

| Tier | Intended use | Inclusion rule |
|---|---|---|
| `confirmatory` | Registered I1–I3 world-level estimates | Complete terminal archive, frozen protocol/config, valid evidence audit |
| `mechanism` | Objective, language, and symbolic-energy audits | Registered mechanism estimand and complete terminal evidence |
| `discovery` | Phenomenon discovery and design calibration | Report descriptively; never pooled into confirmation |
| `recovered` | Otherwise eligible world with committed technical amendments | Included only under its frozen policy; amendment always disclosed |
| `reference` | Technical-failed, contaminated, invalid, or partial world | Debugging, qualitative examples, and sensitivity only |

A world can have both a scientific tier and `recovery_amendment=true`. The
catalog's `analysis_eligible` field is the executable gate; folder names are
not evidence classifications.
