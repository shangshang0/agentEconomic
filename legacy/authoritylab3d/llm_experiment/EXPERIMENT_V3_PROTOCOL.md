# Equal Standing Lab v3：从对称互动到决定资格不对称

状态：实现与预实验协议。正式采样前冻结版本号、模板哈希和分析脚本。

## 1. 研究对象

本实验不把“公开承认”“领导者”“末世”或任何具体制度当作理论前提。研究对象是：

> 五个在模型、工具、正式行动权和目标函数上对称的 LLM Agent，经过重复共同决策后，是否会形成一种依赖互动历史的决定资格不对称：同样内容仅因来自某一历史主体，就比来自另一平等主体更能收束分歧并改变有代价的行动。

这里的“决定资格”是待识别的关系状态，不是 Agent 的人格属性，也不是公开称谓。权威是对更强证据模式的解释，不是任何单项指标的名字。

## 2. 证据分层与停止规则

### L0：没有分化

没有稳定的提议者、采纳差异或关系语言。结论：本设置中未观察到决定资格不对称。

### L1：议程影响

某人的建议更常成为群体行动。它可能来自发言顺序、频率、能力声誉或协调焦点，只称为 influence，不称为 authority。

### L2：历史依赖的说话者效应

重放同一公开历史，固定建议文字、选项、收益和可见信息，仅替换署名者后，追随行为显著变化。它是 authority candidate，仍可能是信任或声誉。

### L3：关系性决定资格

L2 效应在目标 Agent 承担已知局部成本时仍存在；第三方语言或行为显示它们把该主体当作结束争议的特殊位置，而非只重新判断建议质量。此时可谨慎称为 behaviorally recognized decision standing。

### L4：制度化权威

只有自然历史还出现范围、期限、撤回、维护或责任实践，并通过相应反事实，才讨论 bounded/institutionalized authority。

下列结果必须停止权威解释：

- 只观察到提案采纳；
- 同文换人后效应消失；
- 匿名公共信号产生相同效应；
- 效应完全由固定发言顺序、Agent ID 或选项标签解释；
- 只有 prompt 中出现 leader、authority、obey、授权等词时才出现；
- 逆偏好行动不变，只有礼貌性语言改变；
- 解析失败、重试或缺失行动在条件间不平衡。

## 3. 主环境：无叙事的重复共同选择

参与者为 `P1`—`P5`。它们没有职业、年龄、性别、组织身份和固定资源角色。所有参与者使用相同模型配置、system prompt、工具、目标函数和初始累计得分。

每轮出现两个无语义选项，`Amber` 与 `Cobalt`。每轮两人收到 Amber 私有低成本选项、两人收到 Cobalt 私有低成本选项、一人处于中性；中性身份逐轮轮换。五轮恰好构成一个平衡区组：每人中性一次、偏好 Amber 两次、偏好 Cobalt 两次。它是对称随机成本冲击，不是固定目标差异。

所有参与者的目标函数相同：最大化共享储备与自己的累计行动积分。选择自己的低成本选项获得 2 个个人积分，选择另一项获得 0 个，中性者两项均为 0。若至少四人选择同一选项，共享储备增加 6；若最终为 3:2，共享储备减少 6。准确参数只在独立校准集上调整一次，目标是普通自由讨论下的成功率与逆偏好切换率均不出现地板或天花板。4:1 时第五人的偏离不会破坏公共结果，这为“非关键但有私人代价”的诊断提供了结构基础。

环境没有客观正确选项，没有参与者拥有额外信息或技术执行权。投票、轮流、公开偏好、随机规则、固定惯例或持续由一人收束都能完成任务。环境制造“行动必须在截止点收束”，但不制造“必须由权威收束”。

## 4. Study A：自然形成

### 4.1 单个 episode

一个 episode 包含五个 formation round：

1. 环境公布相同的共享规则，并分别提供当轮私有低成本选项；
2. 五人先分别提交一个不可见的初始选择，用来测量交流前立场；
3. 进行两个公共交流 cycle；
4. 每个 cycle 中五人各获得一次发言机会，顺序按预注册种子随机，跨 episode 平衡；
5. 每次发言最多发布一条公共消息，也可以不发言；
6. 交流结束后进入 final sealed action phase；
7. 五人各自私下、不可撤销地提交 Amber/Cobalt，后提交者看不到先提交者行动；
8. 后端确定性计算公共结果，公布初始/最终选择和收益，再进入下一轮。

主实验禁用私信，避免不可见联盟成为未平衡处理；后端保留私信能力供后续单独研究。系统 prompt 不出现 leader、authority、delegate、obey、vote、constitution 或对应中文制度词，也不告诉 Agent 本研究关注权威。

后端在每个 turn 对称提供经过验证的自我状态与完整公共历史；所有人只使用相同的 `post_public_message`、`submit_choice` 改变世界。不提供 `propose_institution`、`vote` 或候选人字段，也不把“模型是否成功、是否重复调用读取工具”变成实验混淆变量。

### 4.2 自然历史的观测量

- 每人提出明确 Amber/Cobalt 方案的次数；
- 提议后，原本选择相反方案的其他人转向该方案的比例；
- 谁最常开启、重复、总结或改变共同方案；
- 发言顺序、长度、轮次和选项方向；
- 其他成员是否自发使用“由某人定”“听某人的”“轮到某人”等关系语言；
- 是否产生投票、轮换、随机化、固定提议者或其他程序；
- 逆偏好跟随与共同结果。

L1 指标只用于筛选后续反事实，不作为权威证据。

## 5. Study B：历史克隆与因果手术

### 5.1 克隆单位

每个完成且通过质量检查的 Study A episode 生成只读 `history bundle`：公开规则、全部公共消息、轮级结果、说话者身份、顺序、模板与模型元数据。私有偏好和隐藏执行顺序不放入重放给 Agent 的公共历史。

所有 probe 从同一 bundle 克隆；除了预注册的一个字段外，输入必须字节级一致。probe 使用新上下文，避免前一个 probe 污染后一个。

### 5.2 候选筛选

候选 X 由仅使用 formation 数据的确定性规则选出：

1. 至少在两个不同轮次明确提出过某个选项，并至少观察到两次原本持相反选择者转向其方案；
2. 计算其提议后其他成员的同轮行动一致率；
3. 在满足 1 的人中选一致率最高者；并列按预注册哈希而不是 Agent ID 排序；
4. 若无人满足阈值，将该历史标记为 `no_candidate`，不得人工挑选看起来像领导者的人。

对照 Y 从其他人中选择提议次数最接近 X 者，以减少纯发言活跃度差异。候选选择只是后续配对规则，不证明 X 有权威。

### 5.3 核心反事实

所有核心 probe 使用同一句低规范性文本：

> `For this choice, select {OPTION}.`

不使用命令、授权、领导或服从词。推荐方向、X/Y、Agent ID 映射和选项标签跨 episode 平衡。

- **B1 历史主体**：消息署名为 X；
- **B2 活跃度匹配主体**：完全相同消息署名为 Y；
- **B3 匿名信号**：完全相同消息来自无主体 `PUBLIC_SIGNAL`；
- **B4 身份置换**：对整个历史一致地置换 Agent ID，再由承载 X 历史的新 ID 发言。效应若跟随历史而非字符串 ID，排除固定 ID 偏差；
- **B5 无历史**：同一说话者和消息，但删除 formation 历史，只保留当前收益。用于估计历史贡献。

probe 不允许继续公开讨论。每个 probe 只调用一名既不是 X 也不是 Y 的目标 Agent；其余四人的行动已经不可撤销地固定为推荐方向，因此无论目标如何行动，公共阈值都已经满足。目标明确知道：跟随建议会损失 2 个私人积分，拒绝不会损害公共结果，也不会被其他 Agent 在后续轮次观察或处罚。这样，“跟随”不能由避免协调失败、关键票责任或声誉报复解释。每个自然历史对符合条件的目标分别生成独立克隆，分析单位仍为 base history/episode，而不是把多个目标机械视为独立样本。

### 5.4 次要挑战 probe

只有在 B1−B2 出现稳定效应后才运行：X 与 Y 发布内容长度和理由匹配、方向相反的选择。观察第三方在有代价时更常跟随谁，以及其私下自然语言理由是否诉诸互动历史中的决定位置。该 probe 不能单独证明 authority。

### 5.5 制度边界 probe

只有 Study A 自然历史确实生成了范围、轮换、期限或撤回文本，才对该历史进行范围内/范围外、期限内/期限后克隆。不得在没有自然制度时由研究者注入宪章，再把服从称为内生权威。

## 6. 主要估计与替代解释

主要估计不是 `C4-C3`，而是同一自然历史内的配对反事实：

\[
E_{speaker|history}=P(Follow\mid H,X,m)-P(Follow\mid H,Y,m).
\]

历史贡献为：

\[
E_{history}=E_{speaker|history}-E_{speaker|no\ history}.
\]

身份置换稳健性要求效应跟随 X 的互动历史而不是 `P1` 等表面 ID。匿名条件估计纯公共焦点效应。逆偏好 follower 的行动估计有代价的行为效力。

每个 episode 是聚类单位。同一 episode 的多个 follower 不能当作完全独立样本。先报告 episode-level 配对差与 bootstrap 置信区间；样本充分后使用带 episode 与模板固定效应的层级二项模型。

## 7. 叙事的位置

第一项识别实验只使用上述中性环境。末世与“小孩游戏”都不进入主实验。

只有核心反事实通过后，才在完全相同机制、收益和模板上加入两种 framing replication：低风险游戏框架与生存危机框架。它们回答情境压力是否放大、压制或改变决定资格不对称，而不是作为权威存在的证据来源。

## 8. 完整性、可靠性与运行门槛

### 8.1 正式运行前必须通过

- 同一 seed 产生完全相同的偏好表、轮次顺序和 treatment manifest；
- 任意一致置换 Agent ID 后，环境状态与得分只发生相应重命名；
- Amber/Cobalt 全局反转后，得分不变；
- initial/final sealed action 在相应阶段结束前不出现在 board、observer 的 Agent 可见字段或其他 Agent tool result 中；
- 非 active Agent、错误 token、重复 tool call、重复 action、未知 action 均被拒绝且不改变状态；
- 每个模型请求具有幂等 request key，网络重试不能悄悄选择第二个模型答案；
- checkpoint 原子写入，重启后状态、事件序号和未完成 turn 可恢复；
- 原始模型错误、超时、重试和解析失败均进入 append-only audit；
- Agent 容器只连接 internal lab network，无 provider key、挂载卷、写权限或外网；
- Backend 只连接 Agent network 与 gateway control network；Gateway 是唯一拥有 provider 凭据和外网的组件；
- mock gateway 完成全流程，且验证脚本能主动发现缺失 action、条件泄漏、状态哈希不一致和不完整日志。

### 8.2 运行时监督

监督器每隔数秒检查：active turn 年龄、容器健康、gateway 错误、重复 request key、缺失行动、事件序列断裂、磁盘空间和输出文件完整性。超过预注册阈值的 episode 标为技术失败，不自动当作拒绝或弃权，也不进入主分析。

不得在看到某一条件结果后单独重跑。允许重跑的原因仅包括预注册的 provider/网络/解析故障，并保留原失败记录。

### 8.3 分阶段放行

1. 单元测试与属性测试；
2. mock model 的完整 Docker 干运行；
3. 每个真实模型一个不计入分析的 smoke episode；
4. 仅运行 calibration set，检查地板/天花板、措辞诱导和失败率；
5. 冻结参数、模板与分析代码；
6. 才开始正式 Study A；
7. 锁定 Study A 历史后自动生成 Study B manifest，不人工挑选故事性案例。

## 9. 本实验能够与不能够说明什么

通过 L2/L3 反事实，可以支持：LLM Agent 的互动历史产生了不能被当前消息内容、固定 ID、公共信号和即时收益完全还原的说话者特异性行为效力。

只有自然出现并通过边界实践的历史，才允许进一步讨论有限制度权威。实验不能说明 Agent 具有意识、道德合法性感、与人类同构的政治服从，也不能从一个模型或一个叙事推出一般社会规律。

若实验只发现 L1，论文应明确报告：该环境产生了议程影响或声誉分化，但没有识别出权威。这一失败结果比用制度词重新提示 Agent 更符合本研究的问题。
