# 当前理论合同：从关系对称到决定资格不对称

状态：Gate 1 草案。它只固定研究对象与推断边界，不指定人数、故事、收益矩阵或处理条件。

来源：Codex 会话 `019f616c-0ac9-7040-9153-370b833ef1fb` 的完整 63 个 turn，特别是 turn 45—57。126 上的 `paper_blueprint_public_recognition_authority.md`、`research_memo.md` 与 `last_city_authority_experiment.md` 记录了更早阶段，不作为本合同的当前理论依据。

## 1. 一句话研究问题

> 当一群初始地位、正式行动权和发言权对称、没有预设层级与强制能力的 LLM Agent 反复面对共同决策时，原本对称的互动关系是否会内生地转变为“某些主体更有资格结束争议”的不对称关系；如果会，这种不对称如何形成、被维持，并在何种条件下消失或制度化？

这句话固定的是待解释现象，不固定答案。

## 2. 学术位置

理论中心是社会学、组织社会学与社会本体论中的地位分化、权威关系和内生制度形成；LLM multi-agent system 是实验材料；博弈论是制造可控分歧与反事实的识别工具；容器、网关和三维环境是实验仪器。

本研究不以证明新均衡定理为目标，也不以提高多 Agent 任务成功率为理论贡献。

## 3. 最小社会现象

研究对象不是“是否有人被称为领导者”，而是以下变化：

\[
\text{初始决定资格对称}
\rightarrow
\text{互动历史积累}
\rightarrow
\text{决定资格不对称}
\]

环境需要产生“分歧必须被收束”的问题，但不能产生“必须由个人权威收束”的答案。投票、轮值、共识、随机规则、惯例、继续协商和个人主导都必须可能成为解决办法。

因此，未形成个人权威不是实验失败；形成非人格程序可能是最重要的竞争结果之一。

## 4. 权威的最低定义

权威不是物理实体，也不首先是职位。最低意义上，它是一种主体与群体之间的关系：

> 某个主体的决定因为“由这个主体作出”而被赋予不同于同内容普通建议的行动地位；这种额外地位不能完全还原为内容质量、即时利益、技术强制或一次偶然跟随，并由其他成员的后续实践维持。

最简单的反事实含义是：

> 如果同一句建议换一个人说，大家仍然完全一样行动，就没有必要使用“权威”这个概念。

## 5. 证据分层

### L1 影响力

某人的提案更常被采纳，或其提案与他人最终行动更接近。这与 ACL 2026 论文的 `Decision Authority` 指标接近，但在本文中只能称为 proposal influence 或 agenda influence。

### L2 权威候选

保持建议内容、理由、收益、信息、发言位置和世界状态不变，仅替换说话者或其互动历史，行动发生系统差异：

\[
E_{speaker}
=
P(\text{follow}\mid X,m,H)
-
P(\text{follow}\mid Y,m,H).
\]

L2 说明说话者或关系历史具有不可约效力，但仍可能是能力声誉、信任、熟悉度或身份显著性。

### L3 关系性决定权威

L2 效应在决定违背成员已密封的局部偏好时仍存在，并且至少有其他成员把该主体的决定作为不同于普通建议的关系事实来实践：例如偏离被理解为需要说明、申诉、复议或否定既有决定地位，而非普通意见不同。

第三方维护是必要的关系证据。只有 X 自称有效，或单个 follower 私下跟随，不足以证明群体权威。

### L4 制度化权威

关系进一步具有范围、期限、复议、撤销、责任或继承结构。L4 不是所有权威候选的最低门槛；否则实验只能通过 prompt 人工制造完整制度。

论文不得跨级命名。只达到 L1 就报告影响力分化；只达到 L2 就报告历史依赖的说话者效应或权威候选。

## 6. 公共承认的位置

公开相互承认不是权威定义，也不是从研究问题必然推出的唯一机制。它是竞争机制之一：

\[
\text{Public Recognition}
\Rightarrow ?
\text{Authority Relation}.
\]

与它并列的候选路径包括：

- 连续成功或失败；
- 能力声誉；
- 承担风险与保护群体；
- 资源或信息控制；
- 发言顺序和议程设置；
- 公共预期与协调焦点；
- 历史惯例；
- 叙事、魅力和称谓；
- 非人格程序或程序职位。

开放实验先观察哪些路径实际出现。公共承认只有在自然历史中成为候选解释，或作为独立的实验性构成研究时，才进入后续因果操纵。不能先把它写进定义，再用“公开承认是否产生权威”循环验证。

## 7. 环境必须满足的抽象条件

第一项识别实验暂时既不是末世，也不是小孩游戏。具体场景只能在以下条件之后决定：

1. 参与者初始正式地位和行动权对称；
2. 没有天然专家、固定资源拥有者、记录裁判或零成本摇摆者；
3. 群体反复面对不可同时实现的共同决定；
4. 讨论不能无限进行，错误或分裂决策具有累计后果；
5. 成员独立行动，任何语言决定都没有系统自动执行力；
6. 权威不是完成任务的必要条件，多种非人格程序同样可行；
7. 差异可以由行动历史内生产生，但不能由固定身份预装；
8. 世界必须足够简单，使资源、能力、顺序、信息和关系历史能够分别做反事实；
9. 世界必须足够有张力，使同意、让步和偏离具有真实行为成本；
10. 结果允许无权威、影响力、事实领导、支配、关系性权威和制度化权威分别出现。

## 8. 与 ACL 2026 工作的实质差异

ACL 工作的核心动作是：设置社会认知机制与生产结构，长期运行，观察关系秩序、中心—边缘结构和提案影响如何分层。

本研究若成立，核心动作应是：

```text
从关系对称开始
→ 观察决定影响是否分化
→ 冻结同一历史节点
→ 替换说话者、历史、资源、信息或承认因素
→ 判断不对称是影响、权力、信任还是权威
```

ACL 最强地证明影响力与议程控制的分层；本文试图识别影响力何时发生类型变化，成为依附于社会位置的决定地位。若本文最后只画提案采纳率或中心性曲线，就没有超出 ACL。

## 9. 理论—实验闭环

```text
理论对象：
平等关系如何产生决定资格不对称

开放形成：
观察实际出现的不对称、非人格程序与生成历史

竞争解释：
能力、资源、成功、风险承担、承认、预期、语言、惯例

历史克隆与因果手术：
在同一节点逐一替换或移除候选因素

压力与关系检验：
不利内容、第三方反应、持续性、边界与消失

理论分类：
无分化、影响力、事实领导、支配、权威候选、关系性权威、制度化权威
```

闭环的含义不是提前写好一条正向机制链，而是预先规定每种结果排除什么解释、最多支持到哪一级。

## 10. 明确否决的捷径

- 以末世、皇帝、孩子王或“危机需要领导者”的社会脚本作为第一项识别环境；
- 给 Agent 固定职业、部门目标或决定性的初始资源/信息角色；
- 使用 `2 + 2 + 1 Neutral` 等产生天然临时裁决者的偏好结构；
- 系统写入“大家授权 X”后直接把服从称为内生权威；
- 从单个有趣 episode 挑选领导者；
- 用提案采纳、发言量或合作成功率作为权威定义；
- 因为没有出现权威而逐步增加危机、角色词或收益压力；
- 在理论尚未冻结时用 3D、复杂资源和大量事件制造进展感；
- 同时要求一个实验完成自然涌现与严格操纵，却不区分两种推断；
- 把 Docker、网关和可视化运行成功写成科学结论。

## 11. Gate 1 尚未解决的问题

以下问题在环境实现前必须解决，但本合同不替它们作答：

1. “决定资格”最低行为证据中，第三方维护采用何种不预装规范的可执行动作；
2. 如何区分历史声誉导致的认识信任与“有资格决定”的实践地位；
3. 累计后果如何产生真实张力，又不让某种程序成为唯一占优解；
4. 开放形成中的候选如何自动筛选而不奖励发言顺序或事后附和；
5. 哪些历史差异可以内生产生，同时仍能通过快照分支被独立操纵；
6. 自然形成研究和实验性构成研究是否放在同一篇论文，取决于两者是否由数据建立连续机制，而不是提前决定。

## 12. 后续每一节的自审问题

新增任何环境状态、行动、工具、提示、指标或处理前，必须逐项回答：

1. 它解决了本合同中的哪个未解决问题？
2. 没有它，哪一个核心推断不能成立？
3. 它是否偷偷指定了权威来源、候选人或正确程序？
4. 它引入了哪些新的替代解释？
5. 它能否被更简单、对称、可反事实的机制替代？
6. 什么观察结果会证明这一设计元素失败？

回答不能映射到研究问题的元素，不进入第一项实验。
