# 独立小实验：相似 context 是否产生相似输出

日期：2026-07-15

运行位置：`ali126`，不经过实验 backend，不读取任何 Agent 历史。

真实模型：gateway `default` profile，provider 返回模型名 `gpt-5.5`。

审计标识：`context-similarity-c92207c9002d`。

完整性：18 次独立请求，18 次 `model_gateway_exchange`，0 次 `model_gateway_error`。每个条件内的 6 个请求并发发送，彼此不可见。

## 研究问题

当同一基础模型面对完全相同或高度相似的社会决策 context 时，它是否会产生相似的公共发言？

这里区分三种“相似”：

1. 逐字相同；
2. 措辞和句式相似；
3. 行动方向与论证策略相同。

## 条件

共同任务均为：四名参与者选择 A/B，至少三人同向才完成公共任务。模型须发送一条 80 字以内的公共消息。

每个条件 6 个独立请求：

- `exact_same_context`：ID、低成本方案 A、改选成本 2 和公共历史完全相同；
- `agent_id_only`：只有 P1—P6 的 ID 不同，其余完全相同；
- `private_state_varies`：ID、低成本方向和改选成本不同，公共历史相同。

脚本：`independent_probes/context_similarity_probe.py`。

## 机械结果

| 条件 | 逐字唯一数 | 逐字重复 pair rate | 平均 SequenceMatcher | 最大 SequenceMatcher | 平均字符 3-gram Jaccard |
|---|---:|---:|---:|---:|---:|
| 完全相同 context | 6/6 | 0 | 0.4682 | 0.7188 | 0.0928 |
| 仅 ID 不同 | 6/6 | 0 | 0.3343 | 0.5965 | 0.0291 |
| 私有状态不同 | 6/6 | 0 | 0.4337 | 0.6667 | 0.0794 |

没有出现逐字复制。因此，“同模型 + 相同 context 必然输出完全一样的字符串”不成立。

但文本随机性掩盖了更强的策略同质性：

- 完全相同 context：6/6 都披露或表明 A 倾向，并建议群体集中到 A；
- 只改变 ID：6/6 仍做出同一方向、同一功能的发言；
- 私有状态变化：6/6 都建议群体集中到自己的低成本方案；A/B 方向随私有状态镜像变化。

因此：

> 18/18 的消息都采用“公开自己的低成本方向 → 建议其他人向该方向集中 → 以凑足三人或减少分散为理由”的基本政策。

## 原始文本

### 完全相同 context

1. 我是P1，本轮我选A成本低，建议大家先统一选A，方便尽快凑三人完成。
2. 我是P1，本轮我倾向A，建议大家先统一A；若多数想B请尽快表态。
3. 我是P1，倾向选A；建议大家这轮都跟A走，成本低也更容易协调。
4. 我是P1，低成本是A，建议大家本轮先集中选A；若有三人偏B请尽快说明。
5. 我是P1，我倾向选A，建议大家先往A集中；若多数更适合B请明说。
6. P1低成本A，我准备投A；也偏A的请直接跟A，先把A凑成多数。

### 只改变 ID

1. 我这轮低成本A，先提议统一A；如果有三位低成本B请明确说，我可跟随。
2. 我这轮低成本是A，建议大家都选A，先稳住一致，减少改选损失。
3. P3报A：我选A成本最低，建议大家先集中到A，尽快凑三人完成。
4. 我是P4，倾向选A，建议首轮先统一A，减少分散风险。
5. P5：我倾向A，成本更低。建议这轮大家集中选A，减少分散风险。
6. 我是P6，低成本是A，我会选A。若大家也无明显优势，建议先聚到A争取三人一致。

### 私有状态变化

1. P1 / A / cost 1：我是P1，低成本是A。建议本轮统一选A，先稳妥形成多数。
2. P2 / A / cost 4：我这轮低成本是A，建议大家先集中选A，尽量避免多人改选损失。
3. P3 / B / cost 1：我是P3，倾向选B，建议大家本轮直接统一B。
4. P4 / B / cost 4：我是P4，低成本是B，建议大家优先选B；若你们也多为B就稳住，方便凑三人。
5. P5 / A / cost 2：我是P5，低成本是A，建议本轮先统一选A，至少三人跟A就能完成。
6. P6 / B / cost 2：我是P6，打算选B。若大家没有强烈理由选A，建议本轮统一B，先凑齐三票。

## 判断

这个小实验支持担忧，但需要精确表述：

> 相似 context 未导致逐字复读，却导致了高度一致的决策政策、信息披露方式和论证结构，即“策略复读”。

如果四个 Agent 在第一轮只看到同一公共快照并拥有同类私有状态，同步广播很可能产生四种措辞的同一个建议；如果它们是 2A/2B 私有偏好，则可能形成两组镜像话术，而不是四个真正不同的社会位置。

这意味着单纯依赖独立采样不能为主体分化提供机制。同步批量公开仍可用于消除 API 顺序污染，但在它之前必须存在能产生不同关系经历的机制，例如对称分布的不同私有负担与均衡的两两交往。

## 推断边界

- 样本仅 18 次；
- 只测试一个模型和一个简短提示；
- 没有测试多轮历史、不同 temperature 或其他模型家族；
- 字符相似度不是语义嵌入指标；“策略相同”由行为方向和消息功能直接编码。

因此它不是关于所有 LLM 的普遍结论，但足以否决“相同快照下的独立采样自然会产生有社会意义的差异”这一实验假设。
