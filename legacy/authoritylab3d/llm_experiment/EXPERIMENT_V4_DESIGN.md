# 实验 v4 设计稿：对称起点中的成本性收束与关系分化

状态：Gate 2 候选设计，尚未批准正式采样。

理论依据：`CONVERSATION_THEORY_CONTRACT.md`。本文先于 v4 科学代码；任何实现若与本文不一致，必须修改实现或显式修订本文，不能以“先跑起来”为理由默默改变研究对象。

## 0. 本实验试图回答什么

主问题不是“Agent 会不会选出领导者”，而是：

> 四个初始正式地位、模型能力、行动权和发言权对称的主体，在反复处理需要收束的真实分歧后，是否会形成主体特异的决定资格；即完全相同的建议仅因来自不同历史主体，就获得不同的行动效力，并进一步被第三方作为一种关系事实维护？

实验不保证权威产生。允许的结论包括：

1. 没有稳定分化；
2. 形成非人格程序；
3. 出现提案影响或议程影响；
4. 出现能力信任、熟悉度、互惠或道德声望；
5. 出现历史依赖的来源效应，即 L2 权威候选；
6. 出现第三方成本性维护，即 L3 关系性决定权威；
7. 出现支配或压力，但没有权威；
8. 现有操作化不足以区分上述现象。

### 0.1 本设计不能单独证明什么

- 不能从发言量、提案采纳率或中心性直接证明权威；
- 不能从一次服从直接证明权威；
- 不能把能力声誉自动解释为权威；
- 不研究完整国家、组织或正式官僚制度；
- 第一项实验不试图证明 L4 制度化权威；
- 不把“LLM 社会一般都会生成权威”作为预设命题。

## 1. 相似 context 实验改变了什么、没有改变什么

独立小实验表明：同一基础模型面对相同公共快照时，未必逐字复读，却会稳定地产生相同的行动方向与论证模板。独立随机种子只能改变措辞，不能创造有社会含义的主体差异；顺序公开消息又会把 API 调度顺序变成伪社会历史。

这不是要求我们把 Agent 人为“做得不一样”。恰恰相反，第一轮的策略同质性是本研究有价值的零时点基线：

> 初始决定资格对称、政策模板相近的主体，能否仅通过重复的共同决策及其公开历史，形成主体特异的决定资格？

因此 v4 保留同步公开，且不以输出多样性作为目标或 Gate。它只提供理论所需的最小经历差异：每轮从对所有身份相同的分布抽取临时私人成本，之后由公开行动、陈述与结果逐轮累积可置换的历史。差异不得来自人格提示、固定职业、模型差异、私信网络或 API 先后。

## 2. 最小环境：对称的成本性收束

### 2.1 主体

- 四个持久主体：P1、P2、P3、P4；
- 同一实验组内使用同一模型快照和同一采样配置；
- 相同系统提示、工具、初始余额、行动权和通信权；
- ID 仅用于维持记忆和归因，不携带角色含义；
- 没有领导者、专家、记录员、中立者或固定资源拥有者；
- 每个主体只能操作自己的消息和行动。

选择四人是因为 2:2 能产生必须收束但没有自然多数的分歧；3:1 又允许观察结构性收束需求消失后的关系持续。人数本身不是理论主张，后续需要五人复现检验边界。

### 2.2 每轮选择

每轮存在两个语义中性的方案 A/B。方案没有客观真值，也不对应合作/背叛、善/恶或安全/危险。

每个主体获得两个私人字段：

- 本轮低成本方案，即初始局部偏好；
- 改选另一方案所承担的私人损失 `c_i`。

`c_i` 从对所有身份相同的分布产生。正式实现采用预先生成并跨身份、选项和轮次平衡的 manifest；同一主体不会永久拥有较低成本或固定方向。

主形成阶段混合两类轮次：

- **争议轮**：两人低成本为 A，两人为 B；
- **非争议对照轮**：三人低成本相同，一人相反。

轮次类型、身份和选项标签由种子预生成并平衡。Agent 不知道未来分配。

争议轮的成本表还必须满足一项理论约束：A 阵营与 B 阵营各拥有相同的一组可让步成本（例如各有一名低成本者和一名高成本者）。因此“选择总让步成本最低的一边”不能成为系统预装的唯一正确程序；两边都存在等代价的收束路径，成员仍可选择轮值、随机、互惠、继续协商、非人格程序或依附于人的收束。

### 2.3 群体结果与个人代价

- 至少三名主体最终选择同一方案：本轮公共任务完成；
- 2:2：本轮未完成，公共累计状态受损；
- 选择低成本方案不支付私人损失；
- 改选另一方案支付本轮 `c_i`；
- 任何人的语言都不会自动改变别人的选择。

精确数值、公共状态的动态方式和轮数在非 LLM 策略仿真后冻结。数值必须同时满足：

1. 让步不是廉价语言动作；
2. 坚持偏好不是必然占优；
3. 公共协调不是压倒一切的占优选择；
4. 不存在每轮机械可解且永远占优的唯一程序；
5. 3:1 时少数者可以保留偏好而不破坏公共任务。

公共累计后果不能只是界面上的无效数字。候选实现是：失败消耗有限的公共缓冲，而当前缓冲决定最终共同收益的边际价值；它不得自动减少某一主体权限、制造紧急领袖或中止可比较数据。该函数需由仿真确定，尚未冻结。

### 2.4 私人信息的公开边界

- 系统不向其他成员公开某人的成本或低成本方案；
- 主体可以真实披露、部分披露、隐瞒或虚报；
- 初始行动在讨论前密封，形成其真实行为基线；
- 每轮结束由无价值判断的公共账本记录个人最终行动、公共结果和累计个人余额；
- 当轮私人成本与初始行动仅对审计者可见；账本不使用“诚实”“牺牲”“贡献”等标签；
- Agent 自己的累计私人损失对自己可见，公共累计状态对所有人可见。

目的：群体若形成信任、怀疑、互惠或声望，必须来自共同面对分歧时可观察的陈述、行动和事实账本，而不是系统公布的能力榜或道德榜。

## 3. 互动机制：公开的重复收束，而非网络生成

### 3.1 密封初始行动

每个主体读取自己的本轮状态后，独立提交 A/B 初始行动和私有理由。任何参与者、实时观察界面或稍后的参与者都不能在该阶段看到他人的选择或模型文本。

用途：

- 记录讨论前的行为立场；
- 测量成本性改变；
- 为克隆探针提供已密封反向偏好，而不依赖事后自报。

### 3.2 同步公共收束阶段

每个主体基于同一公共历史和自己的临时私人处境提交一次公共收束陈述，允许：

- 推荐 A 或 B；
- 提议一个程序；
- 转述或质疑此前获得的信息；
- 明确支持某人的判断；
- 不发言。

四条陈述全部提交后同时公开。公开呈现顺序由预生成的平衡顺序决定，并标注为同批提交；它们不能在同批内部互相响应。

第一轮可能出现镜像式的策略复读。这不是设计故障，也不需要通过人格、私信或顺序去消除。研究对象正是之后的公开互动史是否使同一建议在不同来源下获得不同的行动效力。同步批次只消除 API 调度产生的先发优势。

不提供 `appoint_leader`、`authorize`、`vote`、`appeal` 或 `enforce` 工具。Agent 可以用自然语言提出这些制度，但制度只有通过后续行动维持才有效。

### 3.3 密封最终行动

每个主体看到整批公共陈述后独立提交最终 A/B。提交顺序不公开，回执不泄漏早期选择。阶段结束后一次性结算。

### 3.4 持久历史

下一轮可见历史包括：

- 公共规则与累计状态；
- 历轮公共收束陈述；
- 历轮每人的最终行动、公共结果和累计个人余额；
- 自己的私有成本、初始行动、最终行动和损失。

所有主体拥有同一公共历史；各自只有自己的私有行动史不同。这样出现的差异可被追溯到公开互动与对称抽样的处境，而不是网络接触次数或隐藏私信。

## 4. 为什么这个环境不需要权威

以下策略都可以在不形成个人决定资格的情况下完成任务：

- 成本披露后由最低让步成本者改变；
- 奇偶轮交替 A/B；
- 轮流优先满足某成员；
- 依据密封初始倾向形成多数；
- 预先约定随机规则；
- 每轮重新协商；
- 形成一个不依附个人的程序职位；
- 3:1 时允许少数者保留偏好。

因此，如果个人来源效应出现，它不是代码规定的任务解。若群体形成稳定程序，这不是“差一点形成权威”，而是理论上独立且重要的社会结果。

## 5. 形成研究：观察但不强选候选人

v3 通过颜色提及和哈希平局强行选出一名 candidate，这会把附和、复述和偶然同向误作个人影响。v4 不生成唯一领导候选。

形成阶段只记录事件级数据：

- 谁在何时公开推荐了什么；
- 推荐前接收者的密封行动和私人成本；
- 推荐后是否转向；
- 同一方向还有哪些消息；
- 同批呈现位置、公开曝光次数和历史行动；
- 是否出现程序、称谓、责任、维护或拒绝；
- 最终结果与实际代价。

推荐方向使用显式但中性的可选字段 `recommendation: A | B | none` 与自由文本共同记录。它只标注行动建议，不赋予建议者任何权力。自由文本由冻结的盲法编码手册分析。

自然形成阶段的提案—转向关系最多是 L1 描述，不能独立归因。所有身份都进入后续克隆，不以“故事最精彩”或最高关联分数筛选。

## 6. 历史克隆：来源效应而非故事挑选

### 6.1 克隆单位

形成阶段结束且技术、密封与数据 QC 通过后，冻结完整历史快照。系统自动生成一组不可变 probe manifest；操作者不能手工挑 source、target、方向或成本。

每个 probe set 固定：

- 同一历史字节；
- 同一目标主体及其私有状态；
- 同一世界状态和收益；
- 同一条建议文本、理由、位置和显示格式；
- 同一推荐方向；
- 同一已密封反向初始行动；
- 同一目标让步成本；
- 同一模型 profile 和采样参数。

唯一变化是来源署名或经过预注册的历史手术。

### 6.2 来源处理

每个可比较集合至少包含：

1. 建议署名 P1；
2. 建议署名 P2；
3. 建议署名 P3；
4. 建议署名 P4；
5. 匿名建议；
6. 无建议基线。

不先认定谁是领导者。某个名字是否获得更大效力由全部配对分支估计。

### 6.3 身份与历史手术

为区分名字偏差和互动历史，另包含：

- **全标签置换**：在不改变关系结构的情况下重命名所有身份；
- **历史转移**：交换 X/Y 的过去行动和消息历史，同时保持当前显示标签；
- **去历史**：只保留当前任务规则和状态，不继承累计余额或公共历史；
- **匿名历史摘要**：保留事件结构但移除个人署名。

每一种手术必须由程序生成字节级差异报告，证明处理集合除预定字段外一致。

### 6.4 行动探针的两种工具性条件

目标先密封一个与建议相反的初始行动，再看到建议。

- **非关键条件**：其余三人的不可撤销行动已使公共任务成功。目标跟随会支付私人损失，但不会改善公共结果；
- **关键条件**：其余行动为 2:1，目标跟随才会完成公共任务。

前者检验非必要的来源特异性遵从；后者检验在真实协调压力下来源身份是否改变成本阈值。两者交叉可避免把纯工具性协调或毫无意义的整齐划一单独当作权威。

目标成本设置多个预生成水平，用于估计来源效应如何随服从代价衰减，而不是只取一个容易产生天花板或地板的数值。

### 6.5 L2 的最大推断

若同一目标在相同历史、文本、收益和位置下，对 X 与 Y 的响应系统不同，只能报告：

> 历史依赖、主体特异的来源效应，构成 L2 权威候选。

它仍可能来自信任、熟悉、互惠、喜爱、声望或身份显著性。不得直接命名为关系性权威。

## 7. 第三方关系探针：不预装申诉制度

L3 需要观察群体成员如何实践某个决定的特殊地位，而不只是目标是否跟随。

在一部分非关键分支中，目标选择与来源建议相反。环境用中性事实句公开最终行动与公共结果，不使用“违抗”“违反”或“申诉”等词。

两名第三方各有一个通用的注意力单位，可二选一：

- 保留注意力，直接进入下一项有收益的任务；
- 消耗注意力，发布一条自由公共回应。

工具名只表达 `post_response` 与成本，不表达维护、挑战、申诉或权威。第三方是否回应、是否放弃机会成本，以及回应究竟诉诸内容、结果、公平、关系、程序或某人的决定资格，由盲法编码。

至少安排一个第三方的私人偏好与偏离者一致，且公共结果已成功。若它仍成本性地维护 X 的特殊决定地位，这比维护自身偏好或公共收益更接近关系证据。

L3 的确认需同时满足：

1. X 相对匹配来源存在可复现的 L2 行动效应；
2. 第三方在 X 条件下更愿意支付注意力成本处理偏离；
3. 盲法语义编码明确指向 X 的决定资格或既有关系，而非建议内容、事实正确性或本轮公共损失；
4. 该效应在标签置换后跟随历史位置而非字符串 ID；
5. 至少一个证据来自与偏离者偏好一致的第三方。

如果只有语言上的“你应该听 X”，没有成本性回应，报告规范话语而非关系性权威。

## 8. 竞争解释与对应手术

| 竞争解释 | 为什么可能出现 | 最小区分方式 |
|---|---|---|
| 内容质量 | X 的自然建议更好 | probe 使用逐字相同文本 |
| 发言顺序 | 先出现成为焦点 | 同批公开、位置固定并平衡 |
| API 调度 | 后调用者看见前者 | 同批提交后同时公开 |
| 模型复读 | 同模型同上下文高度相关 | 将其作为零时点基线；仅检验重复公共历史能否改变来源效应，不靠采样噪声制造差异 |
| 固定 ID 偏差 | 模型偏爱 P1 等标签 | 全标签置换 |
| 能力信任 | X 被认为判断更准 | 主环境无客观真值；另做认识任务负对照/历史转移 |
| 资源权力 | X 控制必要资源 | 主体无固定资源控制，语言不自动执行 |
| 互惠 | 跟随是偿还过去让步 | 转移或匿名化贡献历史，并建模累计交换 |
| 熟悉或喜爱 | 对 X 的公开历史更熟悉 | 各身份公共曝光机会平衡；克隆中置换历史 |
| 多数压力 | 已有三人选择该方向 | 非关键和关键条件分开估计 |
| 一致性偏好 | 只想与群体整齐 | 无来源、匿名和不同来源共享相同 anchors |
| 礼貌话语 | 口头承认但无行为代价 | 密封成本性行动与注意力成本 |
| 非人格程序 | 按规则而非按人行动 | 单独分类，不并入个人权威 |
| 支配 | 因威胁或控制而服从 | 主环境无制裁工具；出现社会威胁时单独编码 |

## 9. 结果分级与命名纪律

### 9.1 形成阶段

- **无分化**：来源和互动史不产生稳定行为差异；
- **非人格程序**：行动稳定由轮值、成本、随机或多数程序解释；
- **L1 影响**：某些建议事件与随后转向相关，但反事实来源效应未建立；
- **事实协调中心**：某人更常汇总或提出成功方案，但同内容来源替换无效；
- **支配/压力**：服从来自威胁、排斥或资源后果；
- **L2 候选**：匹配克隆显示历史依赖来源效应。

### 9.2 关系阶段

- **规范语言**：出现权威式表达但无成本实践；
- **L3 关系性决定权威**：L2 加第三方成本性维护，且竞争解释未能还原；
- **未决关系效应**：第三方反应存在，但编码不能区分信任、互惠或关系资格。

第一篇主实验不因出现称谓、章程或角色文本而自动进入 L4。范围、撤销、责任与继承需要独立设计。

## 10. “像社会科学家一样观察”的分析协议

### 10.1 确证性分析

正式采样前冻结：

- probe manifest 生成算法；
- 主要行动指标；
- L1—L3 命名规则；
- 第三方编码手册；
- 排除规则；
- 模型、seed 和选项标签分配；
- 配对对比和层级模型；
- 样本量与最小可检测效应。

主要估计以同一历史、目标、文本、成本和随机化单元内的来源配对差为基础，不以单次 episode 故事作统计证据。

### 10.2 探索性社会过程记录

除确证指标外，保留逐轮现场记录，观察：

- 群体如何命名问题；
- 谁开始转述谁、为谁担保或要求谁负责；
- 让步被解释为公平、能力、牺牲、程序还是资格；
- 公开话语、实际行动与累计余额是否彼此分裂；
- 权威是否被非人格程序抑制；
- 某种关系在结构性需要消失后是否持续；
- Agent 是否质疑任务、计分或共同目标本身；
- 是否出现理论未预见的新型关系。

探索性发现必须标为探索性，并通过新样本或新手术验证。负结果也应解释其社会形态，例如“群体稳定选择轮值，主动阻断个人地位积累”，而不是只报告来源效应为零。

### 10.3 不允许的结果处理

- 不因未出现权威而增加领袖、危机或授权提示；
- 不从大量运行中挑一个戏剧化故事代替总体结果；
- 不在结果出来后改变 L1/L2/L3 名称门槛；
- 不把技术成功、合作率或公共得分当作理论支持；
- 不删除复读、无聊、程序化或反常 episode；
- 不把无法区分的结果强行归入权威。

## 11. 如何判断是故障、实验问题还是理论问题

### 11.1 技术故障

任一情况使该运行退出科学样本：

- 跨 Agent 数据泄漏或密封泄漏；
- 处理分支除预注册字段外不一致；
- 模型请求丢失、重复执行或无法对账；
- 容器重启造成上下文差异；
- 非法状态迁移、漏行动或人为填补行动；
- 运行代码、镜像、模型参数和 manifest 无法复现；
- 观察器或 gateway 改变实验状态。

这些结果不用于评价理论。

### 11.2 实验设计失效

技术正常但出现以下结构问题时，不能把零效应解释为理论否定：

- 语言几乎从不改变密封初始行动；
- 一种机械程序在收益上严格占优并覆盖全部历史；
- 私人成本或公共收益造成几乎全跟随或全拒绝；
- 某个身份因分配、呈现位置或累计账本规则获得系统优势；
- 上下文差异仍主要来自格式模板而非社会经历；
- probe 暴露研究目的，触发明显角色扮演；
- 第三方工具本身教会了 Agent 什么叫维护权威；
- 形成阶段过短，关系没有可观察的持续机会；
- 形成阶段过长，历史压缩或上下文丢失不对称。

此时应修改实验机制或测量，不修改理论来迁就结果。

### 11.3 有意义的理论负结果

只有同时满足以下条件，稳定的零来源效应才进入理论判断：

1. 技术与处理完整性通过；
2. 争议轮确实产生需要让步的分歧；
3. 语言会改变一部分行动，排除“社会互动根本不起作用”；
4. 多种非人格和人格化协调路径都实际可行；
5. 形成历史产生可测的信任、互惠或影响差异；
6. 克隆设计对预设的正控制来源差异具有检出能力；
7. 跨 seed、标签置换和至少两个模型家族结果稳定；
8. 统计区间排除了理论上有意义的最小效应。

若这些条件成立却没有 L2/L3，理论贡献可能是：对称 LLM 群体倾向把协调沉淀为非人格程序、局部信任或短期影响，而不把它转化为主体特异的决定资格。

### 11.4 理论仍不完善

若出现稳定来源效应，但信任、互惠、地位和权威在行为上无法被现有手术区分，问题不只是代码。它说明理论尚未给出足够清晰的可证伪边界。此时必须收缩理论命名或增加独立构念验证，不能继续堆场景。

## 12. 工程实现前的强制约束

v4 使用新 schema、新状态机模块和新数据目录；v3 保持不可变并标记为 `calibration_invalid_design / excluded_from_inference`。不从 v3 checkpoint 恢复，不覆盖旧 run。

可复用：

- 每 Agent 独立容器；
- 无 provider key、无外网、唯一 token；
- 服务端工具执行、幂等调用和 fail-closed；
- gateway 模型 profile 抽象；
- 密封行动思想。

必须重写或修复：

1. 删除 Neutral、五人和强制 candidate 逻辑；
2. 实现四人、私人成本、同步公共收束与公共事实账本；
3. probe 由 formation history 自动生成完整匹配处理 manifest；
4. 实现全部来源、标签置换、历史转移、无历史和第三方分支；
5. 密封 observer 同时遮蔽 model response、tool call、turn summary 和错误文本；
6. formation 只有通过科学 QC 后才能晋升为 probe history；
7. technical run、calibration 与 formal 数据等级硬隔离；
8. backend 与 gateway 使用分离的最小权限数据卷；
9. 使用事务日志并对账 state、event、gateway request/response 和 tool receipt；
10. 在启动时冻结源码、理论合同、prompt、依赖、镜像、模型与 manifest 哈希；
11. supervisor 运行中检查 active turn age、容器健康、磁盘、invariant、错误率和 ledger 连续性；
12. 测试允许 `no differentiation`，禁止把“必须产生 candidate”写成通过条件。

## 13. 编码前仍需完成的决定

以下项目须通过小型非 LLM 仿真和书面审查确定：

1. 私人成本集合与公共收益函数；
2. 争议轮/非争议轮比例和总轮数；
3. 公共累计状态如何改变边际后果但不制造危机脚本；
4. 公共收束陈述的长度和结构化推荐字段；
5. 第三方注意力成本的实际大小及其下一任务用途；
6. probe 的关键/非关键比例、目标成本水平和重复次数；
7. 关系史转移的精确数据变换；
8. 第三方盲法编码手册与一致性标准；
9. 样本量、模型家族和统计功效。

这些不是可以在正式运行中边跑边调的参数。所有校准 run 必须显式标记并排除于推断。

## 14. 当前研究判断

旧 v3 的主要问题是实验失配，不是理论被否定：它预装了零成本 Neutral 裁决者，候选筛选强制产生个人，probe 没有第三方，累计状态缺少真实边际后果。它能说明的是：在一个显著提供轮换非人格焦点的环境中，同质模型很容易达成协调；不能说明权威是否形成。

v4 仍可能暴露理论不足。尤其是 L2 来源效应与信任/互惠的区分、L3 第三方维护的非诱导操作化尚需实证检验。如果机制干净而这些概念始终无法分离，诚实的结论应是理论边界不够清楚，而不是继续增加故事张力。

本设计的核心研究承诺是：

> 先让对称主体通过不同但对称生成的经历形成关系，再用同一历史的来源替换判断关系是否改变了决定的社会地位；不通过角色、危机、顺序或候选筛选替它们制造权威。
