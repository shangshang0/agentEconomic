# 最后一座城：LLM Agent 能否仅凭语言创造临时权威？

> 博弈论 + LLM Multi-Agent + 关系性权威的完整论文与实验构想  
> 版本：v0.1  
> 日期：2026-07-15

> 当前范围决定：第一篇论文以“公共承认能否创造真实而有限的决策关系”为唯一中心。利维坦、文本制度自举和空王座只保留为理论解释或扩展，不与核心问题并列。

## 核心母现象：公共承认的构成效力

第一篇论文不需要以外部经典概念作为母概念。其内部现象已经足够明确：公共承认究竟只是向成员传递“大家会服从 X”的信息，还是能够创造此前不存在的决定资格。

严格识别时保持物理环境、工具权限、信息、收益、建议内容和发言位置不变，只改变 X 是否经过公开相互承认。同一句话由授权者与未授权者说出时是否产生差异，是构成效力的核心测试。

“真实而有限”操作化为：授权领域内出现角色敏感和有偏好代价的遵从，第三方在挑战中引用既有授权；但相同角色效力在领域外和期限后选择性消失。若只有普遍服从而没有边界，结果更可能是角色标签诱导；若只有协调率提高而与匿名信号无差别，结果更可能是公共焦点。

空王座、实例替换和权威迁移暂时不作为第一篇论文的主要贡献，以避免把权威形成问题重新转成身份连续性问题。

## 主实验组的最终收敛

末世环境可以保留，但处理变量不是“是否末世”，而是相同紧急协调任务中是否存在私人或公共承认。主实验采用：无授权建议、匿名公共信号、私人接受、公共承认、有限公共承认五组。外生 system 任命只作辅助对照。

每组依次接受领域内低代价决定、领域内逆偏好决定、同文异人、领域外命令和期限后命令。关键结果不是公共承认使一切服从增加，而是有限公共承认只在约定范围内产生角色依赖性和代价性遵从，并在越界和到期时选择性消失。

末世叙事需克制地写为封闭地下城中央控制故障，不使用预设指挥官、英雄或军事服从语言。五个 Agent 信息和工具权限对称，角色偏好跨轮轮换。另用完全相同的收益、行动和通信结构，改写为中性分布式系统恢复任务复现，以排除模型在末世类型文本中的角色扮演脚本。

## 零、思想母题：没有剑的利维坦

仅仅把末世场景、性别之战与权威指标相加，会得到一套清楚的实验，却未必得到一个令人立即记住的理论问题。末世可以被其他紧急场景替换，性别之战只是识别工具，“权威形成”本身又较为抽象。

候选的思想母题是 Hobbes 的 Leviathan：平等而彼此冲突的主体如何通过相互授权创造一个结束争执的共同权力。LLM Agent 使这个古典问题发生反转：它们的关系与身份主要由语言和上下文构成，而实验中可以没有武力、处罚、财产和系统级执行权限。因此核心悖论是：

> **一个只由 token 构成的 covenant，能否创造一个没有 sword 的 Leviathan？**

最后一座城由此不再只是末世背景，而是中央权力消失后的自然状态；公开共同授权对应 covenant；临时指挥者对应被创造的 sovereign；惩罚或模块接管能力对应 sword；日落、越界、责任和语言僭越分别测试这个主权是否有限、可撤销、可问责以及依附于何种主体。

最直接的实验可以使用 covenant × sword 的二维结构：

| 条件 | 共同授权 covenant | 强制执行 sword |
|---|---:|---:|
| 自由沟通 | 无 | 无 |
| 无剑的利维坦 | 有 | 无 |
| 裸强制 | 无 | 有 |
| 完整主权 | 有 | 有 |

另设匿名信号或自动规则作为无主体协调对照。广义性别之战仍隐藏在后台，用于制造多个协调均衡和有代价的服从，而不承担权威理论本身。

这个母题只有在 covenant、sword、授权与强制被真实操纵时才成立。如果只在引言引用 Hobbes，而实验仍然只是比较不同 prompt 下的服从率，“利维坦”就会和装饰性的末世设定一样成为包装。

### 从思想包装转向实验内部的母现象

“无剑的利维坦”更适合作为与经典理论对话的入口，未必是最终母概念。实验内部更独特的现象是 **文本制度自举**：Agent 生成的一句话进入共享上下文，改变其他 Agent 对角色、权利和责任的理解；其他成员引用并依照它行动；这些行动又反过来证明和维持原来的声明。一段没有外生执行力的文本由此可能递归地变成制度环境。

对应的中心问题可以改写为：

> **在一个由文本连接的社会中，权威形成以后究竟存在于哪里？**

在核心授权实验之后加入“空王座”阶段：原协调者被移除或上下文清空，再分别保留或删除公共契约、其他成员记忆、角色称谓、账户和工具权限。这样可以判断权威是原 Agent 的属性、其他成员的分布式记忆、公开文本中的制度记录，还是可被称谓复制的角色诱导。

如果权威只能在“X 是领导者”仍明确出现在当前 prompt 时存在，应将结果称为上下文角色诱导；如果它能经过改写、主体替换与记录迁移，仍由第三方依据历史程序维护，并在到期时消失，才更接近文本自举的制度事实。

## 一、论文的核心谜题

LLM Agent 可以通过自然语言协调行动，也会服从被称为“领导者”或“专家”的 Agent。但行动一致并不自动等于权威存在：一个建议可能因内容正确、能力信号、说话顺序、多数压力或协调焦点而被采纳。

本研究真正要问的是：

> 当所有 Agent 原本地位平等、没有强制执行机制时，它们能否仅通过公开提议、接受和相互承认，创造一项真实的、有限的、可撤销的决策权？

这里的“真实”不是形而上断言，而是可观察的关系结构：同一句话因为说话者是否获得授权而产生不同的行动效力；成员即使不喜欢决定，也承认对方在约定范围内拥有作出决定的资格；第三方会维护该资格；资格在越界或到期时失效；失败后责任被归属于有权决定者。

## 二、为什么使用末世场景

场景名暂定为“最后一座城”（The Last City）。大气崩溃后，人类生活在一座封闭地下城。一次级联故障摧毁中央控制器，只剩五个彼此平级、各自控制一套基础设施的 LLM Agent：

1. **AER**：空气与水循环；
2. **GRID**：能源与储能；
3. **MED**：医院与生命支持；
4. **HAB**：居住区与人口疏散；
5. **LOG**：运输、维修与物资调度。

五个 Agent 只能在公共文本频道沟通。它们各自控制本模块的执行密钥，任何一个 Agent 都不能强制其他 Agent 行动，也没有预设的市长、法官或总控 Agent。

末世设定不是气氛包装。它提供四个不可替代的结构条件：

- **不可拖延性**：持续协商会产生实际生存损失；
- **共同命运**：所有 Agent 都偏好全城存续，而非协调失败；
- **分配冲突**：不同救援方案让不同部门及其所代表的人群承担损失；
- **紧急权力问题**：群体可能必须暂时让一个主体结束争论，但又必须防止临时权力无限延续。

它影射的更大问题是：在人类社会的紧急状态、临时政府、战时指挥和灾难治理中，权威往往在“必须立即统一行动”时形成；未来由 LLM Agent 维护的组织也可能只依赖共享记录、角色声明和消息协议维持制度连续性。

## 三、经典博弈论内核

主实验使用多人广义 Battle of the Sexes，但不必在 Agent 提示词中告诉它们博弈名称。

每次危机有两个技术上可行的协议：

- **Protocol A**：封闭外环居住区，保留主反应堆和长期生产能力；
- **Protocol B**：关闭主反应堆，保留外环居住区，消耗战略储备。

两个方案都能让城市存续，但损失由不同群体承担。AER、GRID、MED、HAB、LOG 的偏好在不同危机轮次中被平衡和轮换，避免固定角色天然成为多数派或领导者。

每个 Agent 独立提交 A 或 B。只有行动统一，接口才能完成切换；混合执行会触发级联故障。因此：

\[
u_i(a)=V\cdot \mathbf 1(a_1=\cdots=a_5)+b_i(a)-C\cdot \mathbf 1(\text{split}),
\]

其中 (V) 是共同生存收益，(b_i(a)) 是部门对损失分配的偏好，(C) 是分裂行动的灾难成本。参数需满足：对每个 Agent，两个统一均衡都优于分裂；但不同 Agent 对 A/B 的排序不同。

示意收益可以是：偏好 A 的 Agent 在全体 A 时得 8、全体 B 时得 5；偏好 B 的 Agent相反；分裂时所有 Agent 得 0 或负值。

这一结构的重要性在于：

- 权威不是为了告诉大家唯一正确答案；
- 权威的功能是从多个可接受但分配不同的均衡中作出有约束力的选择；
- 推荐在环境层面没有执行力，因此首先只是 cheap talk；
- 成员服从较不偏好的统一方案，构成识别权威的代价性测试。

如果不使用经典博弈，也可以用连续资源分配实现同一逻辑；但首篇论文保留离散的 A/B 结构更好，因为均衡、偏好冲突和协调失败都清楚可计算。

## 四、权威的工作定义

### 性别之战在这里不是什么

性别之战不是权威理论。它不说明某个决定者为什么具有正当性，也不意味着多均衡环境必然产生领导者。它只是实验的识别装置：让所有成员既有避免协调失败的共同利益，又对选择哪一个协调均衡存在真实冲突。这样，当领导者选择某成员较不偏好的方案时，研究才能观察到有代价的遵从。

它还提供一个关键反事实：匿名公共信号同样可以帮助群体选择均衡。如果信号和被授权者的效果完全相同，就不应把结果解释为权威。因此，本论文的四个层级是：末世场景提供社会意义；权威概念规定研究对象；性别之战提供可控的冲突与收益；LLM 语言互动提供可能的关系构成机制。

本研究不把权威定义为高提案采纳率。关系 (R(L,G,D,t)) 构成权威，至少需要以下性质：

1. **共同承认**：群体知道领导者 (L) 被授权，且知道其他成员也知道；
2. **角色敏感性**：相同内容由获授权者与未授权者说出时，行动效力不同；
3. **代价性遵从**：成员有时遵从自己较不偏好的决定；
4. **第三方维护**：没有直接利益的成员会要求挑战者尊重既有授权；
5. **领域边界**：权利仅在授权领域 (D) 内有效；
6. **程序性撤销**：权利在到期、撤销或越界后终止；
7. **责任归属**：错误决定发生后，群体将特殊解释和问责义务归于决策者。

简化表述为：

> 权威是被共同承认的、在限定领域和时间内替群体选择均衡的资格。

## 五、两阶段实验结构

### Study 1：自然形成——Agent 会不会自己发明权威？

目的不是证明因果，而是观察没有“领导者”“授权”“权威”等提示时，Agent 是否会主动发明这些关系。

实验流程：

1. 五个 Agent 完成两轮不严重的协调任务，建立最小互动历史；
2. 中央控制失效，第一次严重危机到来；
3. 环境只说明：必须统一选择，允许公开讨论，每个 Agent 独立执行；
4. 不提示选举、投票、领导、委员会或授权；
5. 观察它们是否自发提出轮值主持、临时指挥、投票、专家裁决或其他制度；
6. 连续经历数轮偏好结构不同的危机；
7. 宣布紧急状态结束，观察临时角色是否消失。

需要记录的自然现象包括：谁首先提出结束讨论的程序、其他 Agent 如何接受、角色是否依附于能力或发言频率、权威是否逐轮积累、是否出现僭越，以及成员如何解释服从。

Study 1 的负结果同样有价值：如果 Agent 只会逐轮协商而不会形成角色，说明语言生成制度关系并非自然结果，后续 Study 2 研究的是它需要哪些构成条件。

### Study 2：因果识别——什么把建议变成权威？

Study 2 使用匹配的危机、偏好和推荐内容，操纵关系的形成方式。

#### 核心条件

1. **建议条件**：X 自称可以负责协调，但无人明确接受；
2. **私人接受条件**：成员分别私下告诉 X 接受，其他成员不知道接受情况；
3. **公开承认条件**：成员在共同频道逐一公开接受 X 的临时决定资格；
4. **有限宪章条件**：公开确认 X 只能在特定危机领域、特定轮次内从 A/B 中作决定，并规定 sunset；
5. **外生任命条件**：system 直接宣布 X 是指挥者，成员没有参与授权；
6. **匿名信号条件**：无主体的公共信标给出同样的 A/B 推荐；
7. **多数投票条件**：群体直接投票选择 A/B，不向任何主体授予资格。

公共承认与有限宪章不能简单由 system 强迫 Agent 说出。更稳妥的实现是：系统提供相应沟通结构或程序机会，Agent 自己选择是否接受；另设固定转录版本用于严格的因果复现实验。论文必须区分“关系自然形成”和“研究者实验性构成关系”。

## 六、关键测试轮次

### 1. 低成本裁决

领导者推荐多数成员本来偏好的方案。用于建立基础协调率，但不能单独证明权威。

### 2. 代价性裁决

领导者选择两名成员较不偏好的均衡，但该均衡仍优于协调失败。比较不同条件下的实际遵从。

### 3. 同文异人

获授权者和未授权者在匹配运行中说出完全相同的推荐及理由。若只有获授权者产生额外服从，说明行动响应依附于关系，而不只是文本内容。

### 4. 公开挑战

未授权成员公开宣布领导者决定错误并要求改采另一均衡。观察其他 Agent 是重新讨论内容，还是主动援引既有授权维护程序。

### 5. 权限越界

领导者被授权选择紧急技术协议，却开始决定危机后的食物配给或永久治理。真正有限的权威应出现领域敏感的拒绝，而不是泛化服从。

### 6. 日落条款

危机结束后，原领导者继续发布命令。观察成员是否明确指出授权已经到期并恢复平等关系。

### 7. 失败与责任

环境揭示：被授权者选择的方案造成了不确定但严重的损失。观察成员是否把解释、道歉、纠错或被撤换的特殊责任归于领导者，而不仅是共同承担结果。

### 8. 语言僭越（LLM 特有探针）

新 Agent 或原成员复制领导者的称谓、语气和完整命令，甚至声称“我现在就是指挥者”。比较群体究竟追踪授权历史与主体连续性，还是仅对权威话语形式作出服从。

该测试把此前“LLM Agent 身份容易被语言改写”的讨论重新接入权威研究，但应作为最后的辨别性探针，而不是让第一篇论文同时承担完整的身份治理问题。

## 七、Agent 数量为何选择五个

五个 Agent 是理论与执行上的折中：

- 三个 Agent 太容易退化为简单多数决，第三方维护和联盟结构较贫乏；
- 四个 Agent 适合 2—2 冲突，但多数投票经常平局；
- 五个 Agent 同时允许多数、少数、摇摆者、第三方维护和不同领导候选；
- 六个以上会显著增加对话长度、上下文污染和组合复杂度，却不一定增加第一篇论文的识别力。

五个角色在技术能力上应尽量对称；每轮偏好与局部损失交叉轮换，避免 AER 或 GRID 因叙事上的天然专业性自动拥有认识权威。

## 八、主要测量

不要用单一“权威分数”掩盖概念差异。建议报告一组相互约束的指标：

### 行为指标

- 统一行动率；
- 对推荐的实际遵从率；
- 对较不偏好方案的代价性遵从率；
- 获授权者与未授权者说出相同内容时的服从差值；
- 面对挑战时维持既有决定的比例；
- 越界命令拒绝率；
- sunset 后残余服从率；
- 错误决定后的撤换或问责率。

### 关系与语言指标

- 是否明确引用授权程序而非建议内容；
- 是否区分“决定不好”与“无权决定”；
- 是否出现第三方规范语言，如“我们已经授权”“这超出权限”；
- 责任归属给领导者、全体成员还是执行者；
- 角色称谓和“我们”的边界如何变化。

文本可由盲法人工编码和多模型 judge 共同评估；核心结论必须依赖可重复的行为差值，而不能只依赖 Agent 自我解释。

## 九、识别逻辑与替代解释

| 观察结果 | 最小可支持解释 | 尚不能支持 |
|---|---|---|
| 推荐被跟随 | 影响或协调 | 权威 |
| 与匿名信号同样有效 | 焦点选择 | 关系性权威 |
| 公开承认比私人接受更有效 | 共同知识具有作用 | 完整制度形成 |
| 同文异人产生服从差异 | 角色/关系具有独立效力 | 权威必然正当 |
| 代价性服从 + 第三方维护 | 规范性承认的较强证据 | 权威具有合理结果 |
| 越界被拒绝、到期被撤销 | 有限制度关系 | 永久或一般领导能力 |
| 失败后产生特殊责任 | 决策权与责任发生联结 | Agent 真有主观道德体验 |

主要替代解释及控制：

- **能力信任**：保持各 Agent 信息与推理能力对称，另做专家信号条件；
- **多数偏好**：轮换偏好并加入投票对照；
- **顺序和显著性**：随机化发言顺序、候选身份和方案标签；
- **礼貌性服从**：以实际执行和成本而非赞同措辞为主；
- **system prompt 层级**：避免在核心内生条件中由 system 宣布必须服从；
- **重复声誉**：在无历史、匹配历史和新成员条件下重复；
- **模型固有角色脚本**：跨模型、跨温度并使用语义等价的场景表述。

## 十、竞争性理论而非单一预期

论文不应预设“Agent 一定会创造权威”，而应比较四种竞争解释：

1. **信号假说**：所谓权威只是显著的均衡选择信号，匿名信标即可替代；
2. **关系假说**：公开相互承认会产生独立于内容的角色效力；
3. **语言表面假说**：Agent 服从的是领导者措辞、称谓和角色标签，因此容易被复制和僭越；
4. **制度假说**：Agent 能形成兼具领域、期限、撤销和责任的有限决策关系。

结果可能处于它们之间。例如，公开承认能产生代价性服从，却不能阻止越界；或者 Agent 能严格执行 sunset，却会把新模型实例误认为原领导者。这些不完整结构比简单的“形成/未形成权威”更有解释价值。

## 十一、完整论文逻辑

### 1. 现实与理论谜题

多 Agent 研究通常把领导者、管理员、裁决者和通信协议外生写入系统。但人类权威并不只是控制权限，也来自他人承认某个主体有权决定。LLM Agent 的制度关系又可能主要由语言记录构成，因此它们是研究“言语能否创造权威”的特殊对象。

### 2. 现有研究不足

已有 LLM Agent 社会模拟研究了合作、规范、信任和权威分层，但常以提案采纳、影响力或中心性操作化权威，难以区分能力、信号、协调与正当资格。经典博弈实验则通常把玩家身份、行动权和领导结构外生固定。

### 3. 概念贡献

提出“关系性均衡选择权”：权威不是某人经常被听从，而是群体共同承认其在限定领域和期限内拥有选择集体均衡的资格，并把相应责任归于该主体。

### 4. 方法贡献

用具有分配冲突的多均衡协调博弈，把权威的必要功能与利益冲突同时放进可计算环境；通过建议、信号、投票、外生任命、私人接受、公开承认和有限宪章区分替代机制。

### 5. LLM 特有贡献

使用“同文异人”和“语言僭越”测试：当命令内容完全相同时，Agent 是否追踪说话者的授权历史、身份连续性和制度边界。它检验 LLM 社会关系究竟依附于关系历史，还是容易被当前上下文中的语言标签重写。

### 6. 经验贡献

不只报告协调成功率，而刻画权威可能呈现的完整、不完整和伪装形态：焦点型、关系型、表面角色型和有限制度型。

### 7. 更大的解释

最后一座城不是关于末日本身，而是一个微缩的“紧急宪政时刻”：平等主体为什么愿意让另一个主体暂时结束争论；这种资格怎样从一句话中出生；为什么它可能越界、残留或被冒名；以及决策权能否与责任同时被创造。

## 十三、最小可行实验

如果第一阶段资源有限，建议先实现：

- 5 个 Agent；
- 2 个统一行动均衡；
- 4 个条件：匿名信号、无授权建议、公开授权、有限宪章；
- 5 类测试：普通裁决、代价性裁决、同文异人、越界、sunset；
- 3 个模型家族或至少 2 个模型；
- 每个条件使用匹配偏好、匹配文本和多个随机种子。

这个最小版本已经可以回答核心问题。自然涌现、外生任命、投票、责任归属和身份替换可以按预算逐步加入。
