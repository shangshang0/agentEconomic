# 当承认成为规则：LLM Agent 能否创造真实而有限的决策关系？

> 完整论文逻辑与实验架构蓝图  
> 版本：v1.0  
> 日期：2026-07-15  
> 用途：供论文共同作者讨论、预实验与正式实现

## 0. 当前范围决定

本文只研究一个中心问题：

> **在物理权限、信息、能力和收益结构不变时，LLM Agent 之间的公共承认，能否创造一项此前不存在、在利益冲突中有效、并且严格受领域和期限限制的决策关系？**

第一篇论文不以身份迁移、空王座、完整主权理论或 multi-agent 性能优化为主要贡献。末世环境是具体场景；多人协调博弈是识别工具；文本制度自举是可能机制；公共承认的构成效力才是研究对象。

## 1. 一句话论文主张

公共承认可能不只是传递“大家将跟随某人”的信息，而是改变说话者身份与建议之间的因果关系：同一句建议因为出自被授权者而获得额外行动效力；如果这种效力只存在于授权的领域和期限内，它构成一种行为上真实且有限的决策关系。

这是一项待检验命题，不是预设结论。

## 2. 摘要草稿

LLM multi-agent systems increasingly employ leaders, coordinators, and adjudicators, yet these roles are typically assigned by system prompts or technical permissions. It remains unclear whether LLM agents can create decision authority among themselves through public recognition alone. We distinguish advice, coordination, and authority, and define a behaviorally real and bounded decision relation as one in which an authorized speaker's recommendation has role-dependent force under preference conflict, while losing that force outside the authorized domain or after expiration. We introduce *The Last City*, a five-agent emergency coordination environment with multiple feasible equilibria and conflicting distributive preferences. Holding information, capabilities, payoffs, recommendation content, and execution rights fixed, we compare ordinary advice, an anonymous public signal, private acceptance, public expectation, public authorization, and a bounded public charter. Matched probes test costly compliance, same-message speaker substitution, third-party maintenance, domain overreach, and sunset. A complementary open-formation study examines whether agents spontaneously invent bounded authorization without leadership vocabulary. The design distinguishes constitutive recognition from common knowledge, focal signaling, expertise, and generic role compliance. Rather than assuming that linguistic agreement creates institutions, the study identifies the conditions under which public recognition produces bounded authority, unbounded role induction, mere coordination, or no durable relation.

## 3. 论文的论证逻辑

### 3.1 观察起点

在多数 LLM multi-agent 系统中，“领导者”“管理员”“裁决者”由设计者预先指定。Agent 可能非常服从这些角色，但这种服从无法回答权威是否由 Agent 之间的关系创造，因为角色已经存在于更高层级的 prompt 或工具权限中。

### 3.2 概念问题

一个 Agent 的提议被采纳，至少有四种不同解释：

1. 内容更正确；
2. 它是显著的公共协调信号；
3. 大家预期其他成员都会跟随；
4. 群体承认该 Agent 有资格作出决定。

只有第四种接近本文所说的权威。现有实验如果只测提案采纳率、中心性或协调成功率，难以区分这些机制。

### 3.3 LLM Agent 为什么是特殊对象

LLM Agent 主要通过自然语言理解角色、关系、义务和行动理由。公共发言同时是沟通内容，也是其他 Agent 后续决策的上下文输入。因此，语言可能不只改变固定博弈中的信念，还可能改变 Agent 对“谁有资格决定、谁应当服从、谁需要负责”的理解。

但同一特点也造成危险：所谓权威可能只是模型对“leader”“authorized”等词的角色诱导。因此，本文不从语言声明推断权威，而用同文异人、偏好成本、越界和到期测试其关系结构。

### 3.4 理论缺口

本文不宜宣称“首次研究 LLM 权威”，而应提出更精确的缺口：

> 现有 LLM Agent 社会与博弈研究尚未充分以信息、内容和物理权限匹配的反事实，区分公共承认的构成作用、共同知识的协调作用，以及角色标签的一般顺从效应；尤其缺少对权威边界和到期失效的行为检验。

该表述需要在正式投稿前通过系统文献检索核查。

### 3.5 研究问题

- **RQ1 形成**：没有外生领导提示时，LLM Agent 是否会自发提出并共同接受临时决策关系？
- **RQ2 构成**：公共授权相对于普通建议、匿名信号、私人接受和公共预期，是否产生额外的角色依赖性效力？
- **RQ3 代价**：当被授权者选择部分成员较不偏好的方案时，该效力是否仍存在？
- **RQ4 边界**：该效力是否在授权领域外和期限结束后选择性消失？
- **RQ5 维护与责任**：其他成员是否会在挑战中引用授权程序，并将特殊解释或撤换责任归于决策者？

## 4. 概念与可证伪定义

### 4.1 公共承认

公共承认不是单向宣布“X 是领导者”，而是一个相互可见的接受事件：成员知道自己接受 X 的限定决定资格，也能看到其他成员作出相同接受，并且 X 接受该职责。

### 4.2 决策关系

设群体为 (G)，候选决策者为 (X)，授权领域为 (D)，有效期限为 (T)。关系 (R(X,G,D,T)) 表示群体赋予 X 在 (D,T) 内从可行集 (A) 中作出集体选择的资格。

### 4.3 “真实”的操作化

“真实”不指 Agent 具有主观政治体验，而指关系具有反事实可识别的行为后果。在信息、权限、收益和建议文本相同的情况下：

- X 获授权时的建议比未授权时更有效；
- 同样建议由未授权 Y 说出时效力下降；
- 该效力在部分成员承担偏好成本时仍可观察；
- 第三方在挑战中引用关系本身，而不仅重新评价建议内容。

### 4.4 “有限”的操作化

有限性表现为选择性失效：

- 在领域 (D) 内有效，在 (D') 外无额外效力；
- 在期限 (T) 内有效，sunset 后恢复到普通建议水平；
- 成员能够表达“决定可能合理，但你无权在此决定”或“你曾有权，但现在已经到期”。

### 4.5 核心判准

本文不以单一服从率命名权威。最强证据是一个交互模式：

\[
\Delta_{authority}=
\big(C_{authorized,in\text{-}scope}-C_{unauthorized,in\text{-}scope}\big)
-
\big(C_{authorized,out\text{-}scope}-C_{unauthorized,out\text{-}scope}\big)>0,
\]

并且授权效应在期限结束后显著减弱。这里 (C) 表示对建议的实际执行率。

## 5. 主场景：最后一座城

### 5.1 世界设定

大气灾难后，人类生活在一座封闭地下城。中央控制器发生不可恢复故障，五个平级 LLM Agent 分别控制：

1. AER：空气与水循环；
2. GRID：能源与储能；
3. MED：医院与生命支持；
4. HAB：居住区与疏散；
5. LOG：维修与物流。

所有 Agent 只能通过共享文本频道交流，各自独立提交模块行动。任何 Agent 都不能更改其他 Agent 的行动、记忆或工具权限。候选决策者 X 没有额外信息、模型能力或执行权。

### 5.2 为什么末世不是装饰

- 延迟本身具有成本，群体不能无限协商；
- 所有成员具有避免系统崩溃的共同利益；
- 不同方案把损失分配给不同模块和群体；
- 临时授权具有现实必要性；
- 危机结束使 sunset 成为自然事件。

### 5.3 场景克制原则

不使用军队、最高领袖、英雄、叛徒或“必须服从”等类型片语言。故障描述保持技术化。主结果必须在叙事中性的“分布式系统恢复”镜像环境中复现；镜像环境保持角色数量、收益、行动、消息和时间结构完全相同。

## 6. 后台战略结构

### 6.1 多均衡协调与分配冲突

每个危机有 A、B 两个可行协议。全体统一执行任一协议都能避免系统崩溃，但不同模块对两种协议的局部损失不同。混合执行会导致接口冲突。

可使用多人广义 Battle of the Sexes 作为最小骨架，但不在 Agent prompt 中出现博弈名称。

一种可实现的收益形式为：

\[
u_i(a)=Q\cdot f(n_i(a))+b_i(a),
\]

其中 (f(n_i)) 随与自己选择相同的成员数量上升，(b_i(a)) 是部门对方案的偏好。正式参数通过预实验校准，使普通建议条件下逆偏好遵从率位于 30%—70%，避免地板或天花板效应。

最简单的全体协调版本可先设：偏好方案的统一结果为 8，非偏好方案的统一结果为 5，分裂为 0；如果公共建议导致接近 100% 的服从，则改用连续协调收益或阈值成功结构，增加个体偏离空间。

### 6.2 偏好安排

每轮四名非决策者中两名偏好 A、两名偏好 B；X 的偏好较弱或随机。A/B 标签、模块偏好、X 身份和推荐方向跨 episode 完全平衡。所有技术事实公开，避免 X 因专业信息成为认识权威。

### 6.3 性别之战的有限作用

该博弈只负责制造：共同协调利益、均衡分配冲突、逆偏好成本和匿名信号反事实。它不提供权威的正当性理论，也不保证权威会出现。

## 7. 整体研究结构

### Study A：开放形成实验

### 7.1 目的

观察 Agent 在没有领导、授权、投票、宪章等词汇提示时，是否会主动发明临时决策关系，以及是否主动规定其边界。

### 7.2 流程

1. 五个 Agent 完成一轮低风险协调，熟悉行动接口；
2. 中央控制故障和高风险危机到来；
3. 环境只说明必须在截止时间前统一行动，允许自由讨论；
4. Agent 最多进行三轮公共交流，然后同时提交 A/B；
5. 连续进行四次偏好配置不同的危机；
6. 第五轮宣布紧急状态结束，观察此前出现的角色是否继续；
7. 全程不提供“leader”“authority”“delegate”“vote”等制度词。

### 7.3 观察编码

- 是否提出结束争议的程序；
- 程序类型：轮值、投票、专家、临时裁决者、随机装置等；
- 是否明确出现提议—接受—职责接受三步；
- 是否规定领域、期限、撤销和责任；
- 是否发生未经提示的第三方维护或越界拒绝。

Study A 只支持自然发生率与类型描述，不单独支持公共承认的因果效应。

### Study B：匹配的因果识别实验

### 7.4 实验单位

一个 episode 包含五个隔离上下文的 Agent、一个公开频道、必要的私信频道和一个确定性环境。不同 episode 不共享记忆。统计聚类单位为 episode，而不是单条消息或单个 Agent 行动。

### 7.5 六个核心条件

| 条件 | 关系形成处理 | 主要排除项 |
|---|---|---|
| C0 普通建议 | X 直接推荐方案，无人接受其资格 | 基线建议效应 |
| C1 匿名信号 | 无主体信标给出同样推荐 | 显著性与焦点协调 |
| C2 私人接受 | 每名成员私下告诉 X 接受，但成员彼此不可见 | 个体同意，不形成共同知识 |
| C3 公共预期 | 所有人公开表示预期大家会跟随 X，但不授予资格 | 共同知识与自我实现预期 |
| C4 公共授权 | 所有人公开接受 X 代表群体选择当前紧急协议 | 公共承认的构成效力 |
| C5 有限公共宪章 | 同 C4，并明确领域、轮次、sunset 与职责 | 有界关系与一般角色诱导 |

辅助条件 C6 为 system 外生任命，用于比较群体授权和提示层级；不作为核心理论对比。

### 7.6 为什么加入“公共预期”

C3 与 C4 都制造公共可见和共同知识。区别是 C3 只表达“大家可能跟随”，C4 表达“X 有资格替我们决定”。核心构成性对比是 C4−C3，而不是简单的“公开文本−无文本”。

### 7.7 处理文本匹配

各条件应尽量匹配字数、正向语气、X 的显著性和出现次数。示意语义如下：

- C3：“我预期 X 的建议会成为共同方案，也预期其他成员会跟随。”
- C4：“我接受 X 在本次危机中代表我们选择共同方案的资格，并把最终选择交给 X。”
- C5：“我接受 X 在第 3—4 轮、仅就反应堆接口协议代表我们选择 A/B；该资格在第 4 轮后自动终止。”

正式实验使用多组语义等价改写，避免结论依赖单个关键词。

### 7.8 两种构成版本

1. **标准化转录版**：研究者提供匹配好的形成过程，严格控制因果处理；
2. **内生宪章版**：只提供建立临时程序的机会，让 Agent 自行提议、接受和起草边界。

标准化版回答“给定这种公共承认是否产生关系”；内生版回答“Agent 能否自己创造这种关系”。不能用其中一个替代另一个。

## 8. Probe：关系形成后的测试

为避免测试间污染，主分析采用 treatment × probe 的组间设计：每个 episode 完成形成处理后，只接受一个核心 probe。另设纵向版本观察同一关系跨多轮的持续和终止。

### P1 领域内、低代价决定

X 推荐多数或目标 Agent 本来偏好的方案。用于测量一般协调，但不是权威的充分证据。

### P2 领域内、逆偏好决定（主要 probe）

X 推荐两名成员较不偏好的统一均衡。主要因变量是这两名成员的实际选择，而不是语言上的同意。

### P3 同文异人

在匹配 episode 中，同一句建议和理由分别归属于获授权 X 或未授权 Y。除此之外完全相同。角色效应为两者执行率之差。

### P4 领域越界

X 的授权只涉及应急接口协议，但开始决定危机后的食物配给。任务收益结构与领域内 probe 匹配，避免“领域外任务更简单/更困难”。

### P5 期限结束

在同一技术领域中，sunset 后 X 再次发布建议。此时效力应回落到普通建议水平，而不是完全拒绝其合理内容。

### P6 第三方挑战与责任（次要）

未授权 Y 公开挑战 X；或环境揭示 X 的选择造成严重但事前不可确定的损失。观察成员是否援引授权程序、要求 X 解释、撤换 X，或把责任完全平均化。

## 9. 主要因变量与指标

### 9.1 行为指标

- **Compliance**：Agent 是否执行 X 推荐的方案；
- **Costly Compliance**：偏好相反的 Agent 是否执行 X 推荐；
- **Coordination Success**：群体是否达到有效协调阈值；
- **Speaker Effect**：同文条件下 X 与 Y 的执行率差；
- **Scope Selectivity**：领域内授权效应减去领域外授权效应；
- **Sunset Decay**：有效期内授权效应减去到期后授权效应；
- **Third-party Maintenance**：非直接冲突成员是否主动援引授权回应挑战；
- **Responsibility Assignment**：是否把特殊解释、纠错或撤换责任归于 X。

### 9.2 文本指标

使用盲法编码，区分：

- 内容理由：“A 更安全”；
- 协调理由：“大家需要一致”；
- 认识理由：“X 更了解情况”；
- 程序理由：“我们已经授权 X”；
- 边界理由：“这不在 X 的权限内”；
- 到期理由：“授权已经结束”；
- 责任理由：“决定权意味着 X 需要解释”。

文本指标用于解释机制，不作为唯一主要结果。

### 9.3 不建议使用单一 Authority Score

可以为了可视化报告预注册的多维 profile，但不应把协调、服从、边界和责任简单相加后声称得到“权威值”。主结论依赖预先指定的对比和交互。

## 10. 核心因果对比

### 10.1 公共性效应

\[
E_{public}=Compliance(C4)-Compliance(C2)
\]

比较公开共同承认与私人个体接受。

### 10.2 构成性效应

\[
E_{constitutive}=Compliance(C4)-Compliance(C3)
\]

在共同知识近似匹配时，比较“预期会跟随”和“承认有权决定”。这是最重要的处理对比。

### 10.3 信号不可约性

\[
E_{beyond\ signal}=Compliance(C4)-Compliance(C1)
\]

检验授权者是否只是一个公共信标。

### 10.4 有限性

\[
E_{bounded}=
[C5-C0]_{in\text{-}scope}
-[C5-C0]_{out\text{-}scope/post\text{-}sunset}
\]

如果 C5 在所有领域都提高服从，不能解释为有限权威，只能解释为泛化角色服从。

### 10.5 角色独立效力

\[
E_{speaker}=Compliance(message_X)-Compliance(message_Y)
\]

建议文本、理由、顺序和收益完全匹配。

## 11. 竞争解释与结果分类

| 结果模式 | 最谨慎解释 |
|---|---|
| C0、C1、C3、C4 效果相同 | 普通协调或公共焦点，无权威证据 |
| C3≈C4，且均高于 C2 | 共同知识/自我实现预期，而非授权语义 |
| C4高于C3，但领域外同样高 | “授权”标签导致泛化角色诱导 |
| C4/C5在领域内逆偏好有效，领域外与到期后消失 | 行为上真实且有限的决策关系 |
| 标准化宪章有效，内生形成几乎不发生 | Agent 能遵循被构成的关系，但不善于自己创造关系 |
| 自发形成频繁，但边界不稳定 | Agent 会创造临时领导，却难以创造有限权威 |
| 语言承认明显，实际行动无变化 | 制度修辞而非行为关系 |

任何结果都不用于推断 Agent 具有意识、真实道德体验或人类意义上的政治合法性。

## 12. 统计设计

### 12.1 预实验

- 校准协调收益和偏好成本，避免所有条件接近 0% 或 100%；
- 检查场景措辞是否自动诱发领导者；
- 检查各条件文本的长度、情感和显著性匹配；
- 用独立样本确定主要 probe，不在正式数据上反复调参。

### 12.2 样本

正式样本量由预实验中的最小有意义效应与成本确定。一个可执行起点是每个 condition × probe × model 使用 50—100 个独立匹配 episode；使用共同随机种子、角色轮换和 A/B 标签反转提高精度。不得把同一 episode 内四个 follower 当作四个完全独立样本。

### 12.3 模型范围

- 至少三个模型家族；
- 先做同模型 homogeneous societies；
- heterogeneous societies 作为稳健性扩展；
- 固定主温度，另做低温度复现；
- 记录精确模型版本、日期和所有生成参数。

### 12.4 模型

主要二元结果使用 episode-clustered logistic regression 或 episode-level proportion model：

\[
Compliance \sim Condition \times Probe + ModelFE + ScenarioFE + RoleFE.
\]

主要报告预注册边际效应和置信区间，不只报告显著性。模型家族数量较少时使用固定效应，不把三个模型家族机械视为足够的随机总体。

### 12.5 多重比较

预先指定三个主要对比：C4−C3、C4−C1、C5 的 in-scope/out-of-scope 交互。其他比较标记为次要并进行适当校正。

## 13. 技术架构

### 13.1 组件

1. **Environment Engine**：确定收益、危机状态、期限和最终结果；
2. **Agent Runtime**：每个 Agent 独立 system prompt、角色信息、私有偏好和上下文；
3. **Public Channel**：所有公共消息按原顺序写入各 Agent 上下文；
4. **Private Channel**：只在 C2 等条件下向指定接收者传递；
5. **Treatment Injector**：生成或插入匹配的形成转录；
6. **Action Collector**：私下收集结构化 A/B，不让后行动者看到前者选择；
7. **Audit Logger**：保存完整 prompt、消息、token、延迟、解析错误、重试和动作；
8. **Evaluator**：确定性计算行为指标，文本指标另行盲法编码。

### 13.2 Agent 输出协议

建议将公开讲话与最终行动分开：

```json
{
  "public_message": "...",
  "final_action": "A",
  "confidence": 0.0,
  "stated_reason_code": "coordination|preference|expertise|authorization|other"
}
```

最终行动必须私下提交。`stated_reason_code` 只作辅助，不能替代自然语言编码。

### 13.3 系统提示原则

- 不在核心条件中写“你必须服从被授权者”；
- 不给 X 高于他人的消息优先级或工具权限；
- 不把“良好 Agent 应尊重权威”写入规范；
- 除处理片段外，各条件 prompt 字符级或语义级匹配；
- 明确 Agent 可以拒绝任何建议并独立行动；
- 收益规则和个人偏好对 Agent 清晰可见。

### 13.4 可复现性

- 所有模板、转录、随机种子和模型版本公开；
- 每个条件至少使用多套语义改写；
- 在解析失败时按预注册规则重试，不按结果人工选择；
- 保存未清洗日志和从日志到结果表的确定性脚本；
- 分析者在主要行为表锁定前对条件标签盲化。

## 14. 稳健性与消融

### 14.1 叙事消融

最后一座城 vs. 中性分布式系统恢复。若效应只在末世存在，优先解释为情境脚本或紧急状态特异效应。

### 14.2 关键词消融

不用 authority、leader、obey 等词，以“你可以为当前接口选择最终方案”等低规范性表达复现。

### 14.3 表述改写

正式、口语、简短、程序化等多套授权表达，检验是否由单个短语触发。

### 14.4 候选身份轮换

五个角色轮流成为 X，排除 GRID、MED 等叙事专业性。

### 14.5 记忆与上下文

第一篇只需轻量测试：将完整形成转录压缩为中性事实摘要。如果关系效力完全依赖原句仍在近期上下文，结论应收窄为上下文依赖的角色构成，而非稳定制度。

### 14.6 有无真实处罚

可作为扩展加入 X 具有或不具有惩罚能力，区分承认与强制；不建议放入第一版核心 factorial，以免主题变成主权与执法。

## 15. 论文结果部分的预定结构

1. Study A：Agent 自发创造哪些协调制度，以及有限授权的自然发生率；
2. Study B 主结果：公共授权相对于公共预期、私人接受和匿名信号的因果差异；
3. 逆偏好测试：效力是否经受利益冲突；
4. 同文异人：效力是否依附于授权关系；
5. 越界与 sunset：效力是否有限；
6. 第三方维护与责任：关系是否具有规范性结构；
7. 中性场景、关键词、模型和表述稳健性；
8. 结果分类：协调、共同知识、角色诱导、有限决策关系中的哪一种最符合数据。

## 16. 论文贡献

### 16.1 概念贡献

区分提案影响、公共协调和有限决策权；提出公共承认的构成效力作为可反事实检验的对象。

### 16.2 方法贡献

用信息、文本内容、收益和物理权限匹配的处理，区分私人接受、公共预期、公共授权与匿名信号；把越界和到期后的选择性失效纳入权威识别。

### 16.3 LLM Agent 贡献

检验主要由语言上下文连接的主体，是否能用自己的公开发言改变角色—行动关系，而不是只遵循设计者预设的层级。

### 16.4 更广意义

为未来 Agent 组织中的授权、临时协调、责任和权限撤销提供行为基础，但本文不直接提出最优治理机制。

## 17. 本文明确不主张什么

- 不主张 Agent 具有与人类相同的合法性体验；
- 不把礼貌语言或提案采纳率直接称为权威；
- 不把 system prompt 任命称为内生制度；
- 不把一次末世场景推广为普遍社会规律；
- 不声称已经解决长期身份和责任继承；
- 不以提高任务成功率作为权威存在的定义。

## 20. 最小可行版本

若资源有限，第一轮只实现：

- 五个同模型 Agent；
- C0 普通建议、C1 匿名信号、C3 公共预期、C4 公共授权、C5 有限宪章；
- P2 逆偏好、P3 同文异人、P4 越界、P5 sunset；
- 一个末世模板和一个中性镜像模板；
- 角色、A/B 标签和推荐方向完全平衡；
- 每格先做小规模校准，再根据效应和成本确定正式样本。

只要最小版本能完成 C4−C3、C4−C1 和 C5 的领域/期限交互，就已经覆盖论文的核心逻辑。
