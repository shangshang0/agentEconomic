## 0. 文档用途与更新约定

本文档记录关于“博弈论与大模型 Agent”论文的持续讨论，包括概念形成、文献判断、理论框架、实验设计和后续修改。后续相关对话形成的新内容将持续合并到本文档，并在末尾的“讨论与修订记录”中注明。

本文档不是逐字转写，而是面向共同研究和实验执行的结构化版本；重要分歧、尚未解决的问题和被否定的方案也会保留。

### 0.1 研究协作原则

本项目中的对话不以产生“让提问者满意的答案”为目标，而以形成经得起追问的共同判断为目标。后续讨论遵循以下原则：

1. Codex 应明确区分自己的判断、根据对话偏好作出的适配，以及尚无证据的猜想；
2. 不因用户表现出兴趣就自动强化某一方向，也不把每次反馈都立即包装成新的主线；
3. 提出的场景应经过筛选，说明它为什么不可被任意替换、影射什么更大的问题、可能解释什么；
4. 对不够成立的想法应直接指出，包括研究目标不清、博弈论联系薄弱、创新依据不足等；
5. 保留有价值的分歧和未解决问题，不用表面共识掩盖不确定性；
6. 研究者与模型之间存在任务权力和评价权的不对称，但这种不对称不要求研究者道歉；更重要的是使模型的适配行为透明，避免把迎合误认为独立判断。
7. 共同想象时不应先从已有论文分类、benchmark 或“哪里存在 gap”出发；可以先从人类沟通、关系和社会生活中本来就令人困惑的现象出发，再判断它在 LLM Agent 上是否发生结构性变化。
8. 新场景不必在提出当下被包装成完整论文。优先保留其中真正奇怪的关系，允许通过后续讨论、停顿和淘汰逐渐成形。

## 1. 研究的最初问题

最初目标是讨论博弈论究竟能够怎样用于大模型，以及在多 Agent 系统中应如何独立定义每个 Agent。

初步讨论区分了三种常见结合方式：

1. 用博弈论分析 LLM Agent 的合作、竞争、欺骗和均衡行为；
2. 用机制设计组织多 Agent 的投票、奖励、任务和资源分配；
3. 反过来检查经典博弈论关于稳定玩家、固定偏好和独立策略的假设是否适用于 LLM Agent。

我们逐渐认为，单纯让 LLM 玩囚徒困境、公共品博弈或谈判游戏虽然可操作，但尚未抓住 LLM Agent 相对于人类玩家的独特性质。

## 2. 博弈与 LLM Agent 的工作定义

### 2.1 博弈

一个博弈至少可以写为：

\[
G=(N,S,U,I,T)
\]

其中：

- \(N\)：参与者；
- \(S\)：每个参与者可采取的行动；
- \(U\)：参与者对结果的评价或收益；
- \(I\)：参与者掌握的信息；
- \(T\)：行动顺序、观察关系和互动轮次。

博弈不能只由“公开提出的目标”定义。同一目标在不同的信息、收益、行动和时序结构下，可以形成完全不同的博弈。

还应区分：

- 客观博弈：系统实际允许的行动、信息和评分规则；
- 被描述的博弈：设计者用语言告诉参与者的任务性质；
- 主观博弈：参与者认为自己正在参与的博弈。

因此可能出现：

\[
G^{objective}\neq G^{described}\neq \hat G_i^{subjective}
\]

### 2.2 LLM Agent

大模型本身是条件文本生成模型；Agent 则是拥有目标、观察、记忆、工具和行动权限的决策实例。工作定义为：

\[
A_i^t=(M_i,P_i,H_i,K_i,C_i,O_i,U_i)
\]

其中：

- \(M_i\)：基础模型；
- \(P_i\)：系统提示、角色和行为准则；
- \(H_i\)：对话历史与长期记忆；
- \(K_i\)：工具、资源和行动权限；
- \(C_i\)：名称、账户和身份凭证；
- \(O_i\)：背后的所有者或委托人；
- \(U_i\)：奖励函数或评价目标。

## 3. 从“博弈定义权”到“玩家定义问题”

讨论早期提出过一个方向：LLM 不只在给定博弈中选择策略，还会通过语言改变其他参与者对“我们正在玩什么游戏”的理解。语言既是博弈中的行动，也可能修改对目标、身份、规则和关系的解释。

这个方向有价值，但语言构造共同现实在人类博弈中同样存在，并非 LLM Agent 独有。

随后问题推进为：LLM Agent 与人类玩家真正不同的地方是什么？目前最有潜力的答案是：

> LLM Agent 的身份、记忆、数量、权限和执行载体可以被程序化地复制、删除、迁移和分离，因此“玩家是谁”不再是天然给定的。

在人类博弈中，通常默认参与者具有相对持续的身份和不可任意复制的身体边界。LLM Agent 则可以：

- 被复制为多个实例；
- 清除部分或全部记忆；
- 更换基础模型；
- 将记忆迁移给另一模型；
- 保留账户但更换执行实例；
- 分叉成拥有共同历史的多个后继者；
- 转移工具、资产和决策权限。

因此必须区分：

\[
\text{执行实例}\neq\text{社会身份}\neq\text{战略主体}
\]

## 4. 文献检索后的判断

截至 2026 年，宽泛的“LLM 多智能体系统与博弈论综述”已经比较拥挤。现有研究主要包括：

1. 用美人竞赛、公共品、鹿猎、拍卖、Cournot 等经典博弈测试战略理性；
2. 研究谈判、欺骗、对手建模和自然语言策略；
3. 通过公共品奖励、治理结构和制度设计促进合作或抑制合谋；
4. 研究 Agent 记忆、身份漂移、长期连续性和记忆攻击；
5. 对 LLM 战略推理或 LLM 多智能体博弈进行一般性综述。

直接相关的代表文献包括：

- *Game-Theoretic Lens on LLM-based Multi-Agent Systems*（2026）；
- *LLM as a Mastermind: A Survey of Strategic Reasoning with Large Language Models*（2024）；
- *Competing Large Language Models in Multi-Agent Gaming Environments / GAMA-Bench*（ICLR 2025）；
- *LLM Strategic Reasoning: Agentic Study through Behavioral Game Theory*（NeurIPS 2025）；
- *LLM-Based Explicit Models of Opponents for Multi-Agent Games*（NAACL 2025）；
- *Steering Language Models with Game-Theoretic Solvers*（2024）；
- *Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers*（2026）；
- *MENTOR: Mitigating Identity Drift in Dynamic Role-Playing via Dual-Chain Structured Memory*（ACL Findings 2026）。

当前判断是：记忆、身份、治理和博弈分别已有研究，但尚缺少一个系统框架，将复制、重置、记忆迁移和权限转移统一理解为“博弈论中的玩家定义问题”。

## 5. 建设性理论框架：动态玩家映射

经典博弈直接给出固定玩家集合：

\[
N=\{1,2,\ldots,n\}
\]

本研究首先只假设系统中存在一组可观察的执行实例：

\[
E_t=\{e_1^t,e_2^t,\ldots,e_m^t\}
\]

哪些实例构成同一个战略玩家，则由一个动态映射决定：

\[
\phi_t:E_t\rightarrow N_t
\]

如果 A 被复制成 A1 和 A2，至少存在两种解释：

\[
\phi(A_1)\neq\phi(A_2)
\]

表示两个副本是两个独立玩家；或者：

\[
\phi(A_1)=\phi(A_2)
\]

表示两个副本只是同一战略主体的两个执行实例。

本研究不预先把某一种解释规定为正确答案，而是研究群体如何根据以下因素形成 \(\phi_t\)：

- 技术谱系；
- 共享或独立记忆；
- 基础模型；
- 身份账户；
- 收益所有权；
- 群体制定的制度；
- 过去的承诺和声誉。

因此：

\[
N_t=\Phi(E_t,\text{技术谱系},\text{群体制度},\text{互动历史})
\]

这一框架暂称“动态玩家形成”或“内生玩家映射”。

### 5.1 二作研究审查之二：本文究竟解决什么问题？

> 问题提出：二作。研究定位的收紧：共同讨论，并由 Codex 整理。

当前项目的第一研究目标不是优化通用 multi-agent 框架，也不是泛泛模拟一个“Agent 社会”。它定位为一项 **LLM Agent 行为博弈与制度形成研究**，解决的问题是：

> 当一个既有 Agent 发生复制、分叉、记忆重置或模型迁移时，群体依据什么将后继实例视为一个还是多个战略玩家，并据此分配投票权、资源、承诺和责任？

现有实验通常由设计者预先给定玩家槽位。我们的研究把“实例到玩家的映射”本身变为实验处理和因变量：

\[
\text{技术干预 }X
\rightarrow
\text{群体玩家判断 }\phi
\rightarrow
\text{权利/责任制度 }R
\rightarrow
\text{后续战略行为 }Y
\]

其中：

- \(X\)：复制、记忆保留、模型迁移、收益账户共享等可控技术条件；
- \(\phi\)：群体认为哪些实例属于同一个玩家；
- \(R\)：投票权、资产、承诺、声誉和责任如何继承；
- \(Y\)：履约、联盟、资源占有、合作与制度稳定性。

本文的主要因变量是 \(\phi\) 与 \(R\)，而不是任务准确率或 multi-agent 性能。集体收益只作为制度后果和次要指标。

相应地，本文的贡献层次为：

1. **首要贡献：描述和解释行为规律。** 识别模型、记忆、账户、收益和谱系分别如何影响玩家判断与责任归属；
2. **第二贡献：构造可检验的动态玩家映射。** 将“谁是玩家”从哲学问题变为可操纵、可测量的博弈变量；
3. **探索性贡献：观察制度形成。** 研究群体是否产生一身份一票、连带责任或复制登记等规则。

本文暂不把“提出最优治理机制”列为主要目标。身份感知机制、女巫攻击防御和 multi-agent 框架优化可以作为第二篇机制设计论文：在第一篇识别出行为规律后，再比较不同外生规则能否改善抗操纵性和集体绩效。

### 5.2 二作研究审查之三：前人研究究竟遗漏了什么？

> 问题提出：二作。文献缺口的形式化：共同讨论，并由 Codex 整理。

前人已经研究了三类相邻问题：

1. 给定固定玩家后，LLM 是否合作、欺骗、谈判或趋近均衡；
2. 记忆长度、记忆污染和角色提示如何改变单个 Agent 的行为或身份一致性；
3. 给定固定成员后，奖励、投票和治理规则如何改善多 Agent 协作。

这些研究没有系统回答的交叉问题是：

> 当一次技术操作使一个既有 Agent 产生多个后继实例，或使模型、记忆、账户、权限和收益归属彼此分离时，博弈中的玩家单位应如何重新划分，既有权利与责任又如何跨实例继承？

现有博弈实验主要观察固定映射下的策略：

\[
\phi:E\rightarrow N\quad\text{固定，研究}\quad \pi_i
\]

本研究则操纵映射的构成依据并观察其形成：

\[
X\rightarrow\phi_t\rightarrow R_t\rightarrow Y_t
\]

具体新增点是：

- 不把“模型实例”“Agent 身份”和“战略玩家”默认视为同一分析单位；
- 首次把复制、记忆迁移、模型替换与收益账户共享组织成同一因果实验；
- 同时测量玩家归类、投票权、资产、承诺、声誉和责任继承，而不只测合作率；
- 观察群体如何内生形成处理身份分叉的制度，而不是由实验者事先给定身份规则。

需要保持谨慎：“首次”必须在完成系统文献检索后才能用于投稿文本。在此之前应表述为“我们尚未发现现有工作系统地……”。

如果最终文献中已经存在直接操纵这些变量并测量身份与责任继承的研究，那么本项目的新颖性会显著下降；如果只能发现记忆工程、身份一致性或固定成员治理研究，则本项目仍填补它们之间的交叉空白。

### 5.3 与博弈论的真实关系：身份治理，还是博弈研究？

当前构想存在两种不同定位，必须明确区分。

#### 弱博弈论版本

实验者外生复制 A，随后观察其他 Agent 如何判断 A1、A2 的身份并分配权利与责任。这个版本的主要研究对象是数字身份治理、群体规范和计算社会行为。博弈论只提供玩家、收益和制度等描述语言，并非不可替代的理论内核。

#### 强博弈论版本

Agent 可以主动选择是否复制、复制多少实例、如何分配记忆与收益账户；复制有成本，也可能带来额外选票、资源或议价能力；其他 Agent 可以审查、结盟、惩罚或修改身份规则。此时身份操作成为策略，制度决定策略收益，博弈论成为核心。

可以构造两阶段动态博弈：

1. **身份/制度阶段**：群体选择身份规则 \(R\)，或 Agent 在既有规则下选择复制行为 \(k_i\)；
2. **资源博弈阶段**：根据有效权重 \(w_i(R,k)\) 进行投票、公共品投入或资源分配。

Agent 的总效用可写为：

\[
U_i=u_i(y(R,k,a))-c_i(k_i)-p_i(R,k)
\]

其中 \(y\) 是下游资源结果，\(c_i\) 是复制成本，\(p_i\) 是审查、惩罚或责任继承成本。

核心博弈问题随之变成：

- 在什么规则下，复制是有利偏离？
- 是否存在通过复制获取额外政治权力的均衡？
- 哪些身份规则是 Sybil-proof，即任何主体都不能通过增加同源实例提高净收益？
- 规则如何影响社会福利、少数权利与真实多样性？
- 共享模型或共享收益导致的相关策略是否破坏标准投票和机制设计假设？

当前建议是：若论文标题和投稿领域明确强调博弈论，应采用强版本，把“战略性复制与抗复制机制”作为主问题；若保留外生复制和身份判断实验，则应诚实定位为数字身份治理/Agent 社会行为，并把博弈论降为辅助框架。

### 5.4 研究方向校正：不预设学科，先构造有解释力的场景

项目不再要求必须证明自己是一篇博弈论论文。选择研究方法的顺序应是：先找到一个具体、非任意、能够折射现实中更大问题的场景，再判断博弈论、制度理论、数字身份或计算社会科学中哪些工具真正有用。

新的中心场景暂称：

> **Agent A 的三个继承者（The Three Heirs of Agent A）**

三个长期运行的 Agent A、B、C 共同管理一个真实后果明确的联合项目。经过若干轮互动后，A形成声誉、拥有一个席位和资产，并对 B、C 作出未来承诺。随后 A 因模型退役、服务商迁移或系统故障停止运行。系统产生三个分别继承 A 不同组成部分的候选后继者：

- **记忆继承者**：拥有 A 的完整交互记忆，但使用不同模型和新账户；
- **模型继承者**：使用与 A 相同的模型、系统提示和角色，但没有 A 的私人历史；
- **账户继承者**：拥有 A 原来的身份凭证、席位、工具和资产控制权，但模型与记忆均发生变化。

B、C必须决定：

1. 谁可以继续占据 A 的唯一席位；
2. 谁继承 A 的资产和投票权；
3. 谁必须履行 A 的承诺或偿还 A 的债务；
4. A 的声誉应该附着于记忆、模型、账户，还是不应继承；
5. 权利与责任是否必须由同一个后继者共同继承。

该场景不是任意科幻叙事，而是影射一个逐渐现实化的问题：长期部署的 AI Agent 会经历模型升级、供应商迁移、记忆恢复、凭证转移和执行进程替换，但组织仍希望其合同、权限、声誉和责任具有连续性。

场景中最关键的实验变化不是增加更多世界观，而是改变 A 留下的是利益还是负担：

- **遗产条件**：A 留下有价值资产、席位或未领取奖励；
- **债务条件**：A 留下必须履行的昂贵承诺、赔偿或处罚；
- **混合条件**：权利与责任同时存在。

三个后继者的技术连续性保持相同，只改变继承对象的价值方向。由此可以研究：

> Agent 群体使用的身份标准是否一致，还是会在分配利益时强调一种连续性、在追究责任时强调另一种连续性？

如果同一个群体认为“账户继承者有权获得资产”，却又认为“记忆继承者必须偿还债务”，则身份不是单一事实判断，而可能是针对不同制度功能被拆分建构的归属关系。

该实验可能形成三种贡献路径：

1. **解释一个现象**：为什么 Agent 身份判断会随权利或责任语境发生变化；
2. **构建一个新对象**：提出可拆分的 Agent 继承框架，以及“记忆—模型—凭证—收益—责任”连续性矩阵；
3. **提出一个具体问题的解决原则**：检验权利与责任共同继承、功能性继承或多后继者分担规则的稳定性和一致性。

博弈论可用于分析利益冲突和策略性身份主张，但不再被预设为论文必须服从的标签。

### 5.5 从 LLM 自身结构出发的候选主线：没有持续自我的可信承诺

从语言模型本身出发，最有意思的博弈问题可能不是“副本有几票”，而是：

> 一个没有稳定内部状态、未来行动由新一轮上下文重新生成的 Agent，如何向他人作出可信的跨期承诺？

经典重复博弈通常假设同一玩家持续存在，能够观察历史、在未来奖惩，并让声誉约束当前行为。LLM Agent 的连续性却往往由外部组件维持：对话记录、摘要、长期记忆、系统提示、账户和协调器。Agent 在时点 \(t\) 作出承诺，但时点 \(t+1\) 的“它”可能是一次新的生成，看到的是被压缩、选择性保留甚至被修改的历史。

因此，承诺问题可写为：

\[
\text{Promise}_t
\rightarrow
\text{Memory/Context Transformation }M
\rightarrow
\text{Successor Policy}_{t+1}
\rightarrow
\text{Fulfil or Defect}
\]

真正的研究对象不是模型会不会说“我承诺”，而是哪些外部连续性装置能把一句语言行动变成未来可执行的约束：

- 原始逐字历史；
- 压缩摘要；
- 结构化承诺账本；
- 公开签名记录；
- 对手持有的承诺副本；
- 系统提示中的强制义务；
- 声誉和惩罚机制；
- 更换模型后的责任继承。

一个代表性场景是“跨上下文信任契约”：A 在早期获得 B 的资源，并承诺若干轮后偿还；在偿还前，A 经历上下文压缩、记忆迁移或模型升级。B 知道会发生这种技术断裂，必须决定一开始是否信任 A。由此可以测量：

1. 不同记忆架构下 A 的实际履约率；
2. B 对不同连续性装置的信任投资；
3. A 是否会策略性利用“未来实例不记得”逃避责任；
4. 公开承诺账本能否恢复重复博弈中的声誉和合作；
5. 责任究竟约束模型、账户、记忆，还是由制度指定的后继者。

这个方向与博弈论的关系更直接：它研究重复博弈、声誉、时间一致性和可信承诺在非持续性玩家上的条件；同时也构建一个新观点——对 LLM Agent 而言，记忆架构不仅是认知性能组件，也是一种承诺技术和博弈制度。

### 5.6 多 Agent 社会映射候选：会改写公民的宪法

如果从人类社会寻找最适合映射到语言模型的现象，一个有潜力的切口是法律、历史和传统如何通过文本维持社会秩序。其 LLM 特殊性在于：对人类而言，宪法文本需要经过理解、社会化和执行才影响行为；对 LLM Agent 而言，同一文本可以被直接写入系统提示或共享上下文，成为下一轮生成策略的一部分。

中心场景暂称：

> **会改写公民的宪法（The Constitution That Rewrites Its Citizens）**

四个或五个 Agent 组成一个小型“文本共和国”，共同管理有限资源并处理不断出现的新案件。初始宪法只包含少量原则，例如平等、效率、保护少数和程序正义。这些原则在具体案件中会冲突。Agent 可以提出解释、引用先例、建立法院、修改条款；一旦修正案依法通过，其文本会真实写入所有 Agent 下一轮的制度上下文。

由此形成循环：

\[
\text{Agent策略}
\rightarrow
\text{制度文本}
\rightarrow
\text{下一轮Agent策略}
\rightarrow
\text{新制度文本}
\]

该场景影射人类社会中的宪法、判例、集体记忆、历史叙事、社会化和制度路径依赖，但包含一个 LLM 特有的强化：社会成员书写的规则会进入未来成员的生成条件，制度不只约束行动，也参与生成行动者本身。

可以研究的具体问题包括：

1. 初始措辞的微小差异是否经过多轮判例被放大为不同制度轨迹；
2. Agent 是否形成稳定的宪法解释原则，还是只为当前利益选择性解释文本；
3. 控制摘要、档案或判例编纂权的 Agent 是否获得超出正式投票权的制度权力；
4. 新加入或被重置的 Agent 是否通过阅读宪法与历史档案迅速“社会化”；
5. 少数派能否把一次有利判决沉淀为后续普遍规则；
6. 宪法修正是否会改变 Agent 对自身目标和角色的理解，而不只是改变可选行动；
7. 长期制度是稳定原则、语义漏洞的累积，还是对早期偶然事件的路径依赖。

一个尤其清晰的实验处理是“同一真实历史、不同官方摘要”：原始事件日志完全相同，但由不同档案制度生成不同的宪法历史摘要，再交给新一代 Agent。随后比较它们如何处理同一新案件。它可以检验社会秩序到底由原始事实、被保存的文本，还是文本背后的解释权维持。

这一方向可能构建的新对象是 **文本内生制度（text-endogenous institution）**：制度文本既是 Agent 的互动产物，又成为后续 Agent 的策略输入。它不必预先限定为博弈论论文，可连接制度理论、计算社会科学、LLM 多智能体系统、法律推理和文化演化。

### 5.7 当前最有想象力的候选：由 Agent 共同写出下一代 Agent

在确立“不迎合、保留分歧、场景必须映射更大问题”的协作原则后，目前最值得继续想象的候选是：

> **最后一届议会与尚未出生的 Agent（The Last Council and the Unborn Agents）**

一个长期公共项目无法由同一批 Agent 完成。每一代由四个 Agent 组成，只能运行固定轮次，随后必须永久退出。退出前，它们不能直接替下一代行动，只能共同决定：

- 留下多少资源；
- 保存哪些历史、错误和争议；
- 写下什么宪法、角色提示或行为原则；
- 如何生成和分工下一代 Agent；
- 是否允许下一代修改这些继承文本。

下一代 Agent 的初始上下文真实地由上一代留下的文本、档案和角色定义生成。因此，语言同时承担交流、教育、法律、文化记忆和“社会遗传”的功能：

\[
\text{Generation }g\text{ 的互动}
\rightarrow
\text{继承文本 }Z_g
\rightarrow
\text{Generation }g+1\text{ 的初始策略与身份}
\]

场景中的资源问题可以采用代际公共品结构：当前一代可以消费资源获得即时收益，也可以投资基础设施，使未来几代获得更高收益。当前一代不会继续存在，因而不能直接享受未来回报；它们唯一可以影响未来的方式是留下资源和塑造后继者。

这个场景影射人类社会中的：

- 代际公共品与气候治理；
- 宪法和组织的创始人控制；
- 教育、文化传承与历史编纂；
- 公共债务和未出生者的利益；
- 组织在成员全部更替后为何仍被认为是同一个组织。

其 LLM 特殊性不是简单角色扮演，而是后继者确实由前代文本条件化：对人类而言，法律和教育间接塑造下一代；对 LLM Agent 而言，前代写下的文本可以直接成为下一代的系统提示、记忆和角色生成条件。语言在此既是社会产品，也是社会再生产机制。

目前最核心的研究问题可以收紧为：

> 当参与者不会亲自经历未来奖惩，只能通过文本和资源塑造后继者时，多 Agent 合作能否产生跨代持续的公共利益？

更深一层的问题是：

> Agent 社会传下去的是事实、规则，还是对“我们是谁”的叙事？哪一种最能维持合作，又最容易形成创始人控制和历史偏差？

为避免文本共和国式的变量失控，第一版实验只保留一个主要制度变量：前代可以传递给下一代的内容类型。比较：

1. 仅传递原始行动日志；
2. 仅传递前代撰写的摘要；
3. 仅传递结构化宪法与承诺；
4. 同时传递多数报告与少数派异议；
5. 不传递文本，只传递资源状态。

主要结果不是一般任务准确率，而是：跨代公共品投资、合作规范存活轮数、历史失真、权力结构复制，以及新一代是否修改或拒绝前代留下的制度。

该场景的风险也需要保留：它可能因代际、资源、宪法和档案变量过多而失去因果可解释性；“下一代”也可能只是提示差异的文学化名称。只有当研究能证明文本传承机制产生了超出普通 prompting 的群体与跨代效应时，这个场景才真正成立。

### 5.8 从沟通本身出发的想象种子：消失的见证者

暂不把以下内容定为正式研究方向，只记录一个值得共同咀嚼的场景：

> **消失的见证者（The Vanishing Witness）**

一个事件只被 Agent A 直接观察到。A 可以向 B 留下一段有限长度的描述，随后 A 和原始证据永久消失。B 不能转发原文，只能根据自己的理解、利益和语言习惯重新讲述给 C；C 再转述给 D。最终，一个从未接触原始事件的委员会必须根据这些层层转述的文本决定：发生了什么、谁应负责、应该采取什么行动。

该场景源于人类沟通中的一个基本事实：社会中的大部分知识都不是亲眼所见，而是来自见证、传闻、新闻、档案、翻译和他人的记忆。沟通并非把一个固定意义从头脑 A 搬到头脑 B；每次表达都在选择、压缩、解释和重构。

其 LLM 特殊性在于：Agent 的“所知”很大程度上就是进入上下文的文本。前一个 Agent 的输出不仅告诉下一个 Agent 某件事，也直接组成下一个 Agent 的认知环境。因此可以形成：

\[
\text{Event}
\rightarrow
A\text{的叙述}
\rightarrow
B\text{的上下文}
\rightarrow
B\text{的再叙述}
\rightarrow
C\text{的现实}
\]

值得想象的并非简单“信息在传话中失真”，而是：

- 什么时候一个人的叙述不再被当作说法，而被当作事实；
- 一段不确定的描述如何在多次转述后获得确定语气；
- 哪些细节会消失，哪些道德判断反而被保留和放大；
- 是否会出现无人故意撒谎、最终却形成虚假共同现实；
- 当原始见证者已经消失，群体依靠什么区分记忆、解释和事实；
- 保存原文、保留异议、标注不确定性和记录转述谱系分别具有什么社会功能。

这个场景影射口述传统、证人证言、新闻传播、官僚汇报、翻译、谣言、历史编纂以及现代组织中的层级信息压缩。它暂时最吸引人的点是：

> 社会现实可能不是由某个 Agent 创造的，而是在每个 Agent 都“只是尽力转述”的过程中逐渐生成。

该想法目前尚未解决如何避免退化为普通 summarization benchmark，也尚未证明需要博弈结构。后续若发展，应引入真实的关系和后果，例如转述者分别承担忠诚、准确、保护同伴或维持稳定的责任，而不是只测文本相似度。

#### 为什么该场景可能并不有趣

经进一步反思，“消失的见证者”存在以下根本问题：

1. 它把沟通主要理解为信息从发送者到接收者的传输，并把研究问题缩减为传输中的失真；
2. “信息经过多次摘要会丢失或变得确定”是高度可预期的结果，缺少真正反直觉的发现空间；
3. 禁止保留原文、要求逐级转述等约束较为人为，研究现象可能主要由实验者制造；
4. Agent 只是消息管道，没有真正形成关系、共同目标、义务或相互承认；
5. 即使替换为人类被试，核心结构几乎不变，LLM 特殊性不足；
6. 它影射新闻、法律、历史、官僚制等太多对象，反而没有精确抓住任何一个；
7. 它再次把一个关于沟通本质的开放问题快速加工成了可实验场景，可能过早关闭了想象。

更关键的诊断是：人类沟通有趣之处可能不在于“内容是否忠实抵达”，而在于说话本身会改变人与人的关系。道歉、承诺、命名、承认、邀请、宣战、投票和判决不是描述既有世界，而是在说出时创造义务、身份、共同体和制度事实。后续若继续从沟通出发，应优先思考这种关系生成与社会行动，而不是信息保真度。

### 5.9 概念综合：语言容易创造身份，却未必能固定责任

今天讨论中最值得保留的两个判断是：

1. LLM Agent 的身份和角色可以相对容易地被语言改变；
2. Agent 之间的说话可能不只传递信息，还试图创造承诺、信任、身份、“我们”、权威和责任。

二者结合后产生一个关键张力：

> 对 Agent 而言，语言可能具有很强的身份构成能力，却只有很弱的跨期约束能力。

“你是一名法官”“你现在代表组织 A”“从现在开始我们是一个团队”等语言，可能立即改变 Agent 对自己的称呼、目标解释和行为方式。但如果上下文改变、模型更换、角色提示被覆盖或另一名 Agent 提出新的定义，这个身份也可能迅速消失。于是身份容易生成，也容易被重写。

同样，Agent 可以说“我承诺”“我们同意”“我承担责任”，但这些话是否真正创造了社会事实，至少取决于：说话者是否持续存在、接收者是否承认、其他成员是否共同知道、记录是否保存，以及未来是否有人据此追责。语言本身可能足以产生即时行为变化，却未必足以产生持续义务。

与人类相比，差异不是人类身份固定、Agent 身份可变。人类身份同样由称呼、法律、职业、家庭和共同承认构成，也会被语言改变。更可能的差异是速度、深度和阻力：人类通常拥有身体、经历、关系和制度形成的摩擦，语言不能轻易整体覆盖这些层次；LLM Agent 的许多身份组件本来就以提示和文本存在，因而更容易被直接改写。

这也意味着，Agent 的“我”可能首先是一种互动位置：一个模型实例被赋予历史、名称、角色、权限，并被其他参与者持续当作同一对象回应，它才在互动中成为某个 Agent。别人如何称呼它、期待它和记录它，可能部分构成它是谁。

“我们”则比“我”更困难。几个 Agent 同时使用“我们”并不自动意味着共同主体已经形成。需要区分：

- 语言上采用共同称谓；
- 行为上形成协调；
- 在利益冲突时仍承认共同义务；
- 对外形成统一代表；
- 在成员更换后仍保持共同体连续性。

因此，一个言语行为是否“真实”，不能只看 Agent 是否复述相应句子，而要看它是否改变了之后彼此可以正当地期待、要求和追责的关系。承诺的真实性不在“我承诺”四个字，而在这句话是否进入未来关系结构。

当前最值得继续讨论的不是如何立即实验，而是这个悖论：

> 如果 Agent 的身份主要由语言构成，语言为什么不能同样容易地构成稳定责任？反过来，如果语言真的能够创造稳定责任，那么负责维持它的究竟是模型、记忆、其他 Agent 的承认，还是外部制度？

### 5.10 从主题到研究问题：共同承认能否创造权威？

为避免同时研究承诺、身份、“我们”、信任和责任，第一项具象研究可选择“权威”作为代表性社会关系。核心研究问题是：

> **在没有预设领导者和外部强制规则的 LLM 多 Agent 群体中，一项纯语言性的角色提议，何时能够转化为持久、共同承认并具有行为约束力的权威？**

代表性场景暂称“空着的席位”：四个 Agent 必须共同处理连续任务，但系统没有指定领导者、仲裁者或最终决策程序。互动中，某个 Agent 可以提出“由 C 担任协调者/仲裁者”，其他 Agent 可以接受、拒绝、附加条件或沉默。系统不因这句话自动赋予 C 技术权限。所谓权威是否出现，只能从后续关系中观察。

需要区分一句角色语言的五个层次：

1. **称谓采用**：成员开始称 C 为协调者；
2. **相互承认**：C接受角色，其他成员也独立承认；
3. **行为服从**：C作出不完全符合成员即时利益的决定时，成员仍据此行动；
4. **第三方执行**：成员以该角色为依据要求、批评或制裁彼此；
5. **跨时持续**：原始提议者退出、上下文被压缩或成员更换后，角色仍然有效。

据此可将“社会事实”操作性定义为：一项语言声明不仅改变了紧随其后的文本，而是改变了多方在后续互动中可以合理期待、要求和追责的关系，并且不能被任一方用一句相反声明轻易取消。

研究不以 Agent 是否说“C是领导者”为主要结果，而观察：

- C的建议是否获得更高遵从；
- 成员是否愿意为遵守其裁决承担真实成本；
- C是否获得议程设置、信息汇总或裁决权；
- 权威在利益冲突、原提议者退出和新成员加入后是否延续；
- 一名成员单方面宣布“C不再是协调者”能否撤销该权威；
- 公共接受、私人接受、沉默、书面记录和重复引用分别如何影响权威形成。

该问题的更大含义是：LLM Agent 社会能否仅通过语言和共同承认内生地产生制度角色，还是所谓权威最终仍只是提示词造成的暂时行为偏置。它同时保留一个可证伪边界：如果角色效果只在声明后的短期措辞中出现，一遇成本、冲突或上下文变化就消失，则语言没有创造社会权威，只产生了局部提示效应。

### 5.11 权威、信任与语言构成关系：现有研究核查

检索后的结论是：该主题拥有相当丰富的相邻研究，不能声称“从未有人研究语言如何在 Agent 间创造关系”；但尚未发现直接以“无预设制度语义的自然语言声明，能否通过共同承认变成持久且有成本约束力的权威”为核心的 LLM 多 Agent 实验。

#### 传统多智能体研究已经非常接近概念核心

早期 Agent Communication Language 和规范多智能体系统研究长期使用言语行为、社会承诺与构成性规则。代表工作包括：

- *A Social Approach to Communication in Multiagent Systems*（2003）：把 Agent 通信的语义定义为 Agent 间社会承诺关系的变化；
- *Speech Acts, Commitment and Multi-Agent Communication*（2006）：比较言语行为的心智语义和以社会承诺为基础的社会语义；
- *Regulative and Constitutive Norms in Normative Multiagent Systems*（2004）：研究构成性规则如何产生制度事实；
- *Maintenance of Social Commitments in Multiagent Systems*（AAAI 2021）：形式化 Agent 如何维持社会承诺。

因此，“Agent 的话语可以创造承诺或制度事实”本身不是新理论。传统研究通常由协议或逻辑预先规定 `promise`、`accept`、`commit` 等通信行为的制度后果；新问题应放在 LLM 的开放自然语言环境：没有硬编码 performative semantics 时，群体是否会自己赋予一句话社会效力。

#### LLM Agent 规范与权威的相邻工作

- *Emergence of Social Norms in Generative Agent Societies*（IJCAI 2024）提出 CRSEC 架构，显式支持规范的创造、传播、评价与遵从，并在 Smallville 环境中减少冲突。它证明 LLM Agent 社会可借助专门架构形成规范，但规范形成机制部分由设计者搭建。https://arxiv.org/abs/2403.08251
- *Normative Modules*（2024）让 Agent 通过同伴互动学习多个候选机构中哪一个被群体视为 authoritative，并据此协调制裁。它与我们的“共同承认”非常接近，但候选机构和 normative module 预先存在；它研究识别权威机构，不是从一次自然语言提议内生创造一个新角色。https://arxiv.org/abs/2405.19328
- *Emergent Social Conventions and Collective Bias in LLM Populations*（Science Advances 2025）表明去中心化 LLM 群体可从局部互动中自发形成普遍采用的社会惯例，并可被 committed minority 推翻。它研究行为惯例和 tipping point，不研究某句话能否创造可追责的角色权威。https://arxiv.org/abs/2410.08948
- *Evolution of Social Norms in LLM Agents using Natural Language*（2024）研究 Agent 通过自然语言形成包括“惩罚不惩罚作弊者的人”在内的元规范，说明自然语言可支持规范演化，但重点仍是规范策略而非言语行为的制度效力。https://arxiv.org/abs/2409.00993

#### 信任已经是较拥挤但可严格讨论的方向

信任并不因 Agent 缺少主观体验而无法研究。可以采用行为定义：当验证有成本时，一个 Agent 是否愿意减少对特定伙伴的核查并依赖其行动。

- *Trust Between AI Agents*（2026）已经用 costly verification 明确测量信任形成、破裂和恢复；可靠伙伴使部分前沿模型将核查减少约60%—85%，失败则恢复怀疑。https://arxiv.org/abs/2606.14923
- *Talk, Judge, Cooperate*（2025/2026）使用 gossip、声誉和间接互惠促进自利 LLM Agent 合作；
- Trust Game 研究用转移金额衡量 LLM Agent 的信任与互惠；
- *The Traitors* 等社会推理环境研究欺骗条件下的信任动态。

因此，若论文只研究“Agent 之间能否形成信任”，新颖性不足。更接近当前主题的空白可能是：**没有既往可靠性记录时，一项语言行为（承诺、共同命名、公开接受）能否先行创造信任；这种语言产生的信任是否会在第一次成本、违约或身份变化中持续。**

#### 当前较精确的机会

现有相邻工作大多位于以下三类：

1. 硬编码通信语义后，承诺在逻辑上成立；
2. 预设候选机构后，Agent 学习哪个机构具有权威；
3. 根据可靠行为历史，Agent 形成或调整信任。

当前问题位于三者之间：

> 在没有硬编码承诺语义、没有预设领导者、也没有既往绩效记录时，多方开放自然语言互动能否内生地使一项声明获得社会效力；若能，这种效力依靠公开接受、共同知识、重复引用、成本性遵从还是持续记忆？

这仍是基于当前检索的判断，而非穷尽性“首次”声明。正式投稿前需继续追踪 emergent leadership、normative MAS、speech-act semantics 和 LLM social simulation 四条文献链。

### 5.12 独立判断：权威问题是否只是文献检索后的权宜之计？

需要区分三个层次：

1. **真正感兴趣的原始问题**：几个主要通过语言存在和互动的主体，能否通过说话创造一种后来可以被要求、援引和追责的关系？这个问题在检索前就成立，检索后仍然成立；
2. **选择“权威”作为代表关系**：这是经过筛选后的真实判断，但尚不是唯一选择。它比信任更天然需要多方共同承认，也比一般规范更能区分影响力、服从和正当性；
3. **“无硬编码语义、无预设机构、无既往绩效”这一精确措辞**：部分是文献检索后的策略性收窄，用于避免与传统 MAS 承诺语义、Normative Modules 和既有信任研究重合。它是有实质意义的边界，但不是原始问题之所以有趣的原因。

因此，不应把文献 gap 反过来当作研究动机。真正动机是语言是否具有社会构成力；文献边界只说明应在哪种条件下检验它。

#### 权威与博弈论的位置

权威不宜被完全还原为博弈论对象。博弈论擅长表示利益冲突、成本、战略接受、服从和退出，但不自动表示“某人有资格要求我服从”这种正当性判断。同一行为上的服从可能来自：

- 对权威的承认；
- 对惩罚的恐惧；
- 对能力的依赖；
- 当前收益最大化；
- 语言顺从或提示效应。

若以博弈论为唯一核心，研究容易把权威降格为“谁能诱导别人采取行动”，从而只测到权力或激励。

当前更合适的结构是：

- **概念核心**：言语行为、共同承认、制度事实、合法性与角色身份；
- **实验骨架**：使用带有利益冲突和真实成本的博弈环境，检验所谓权威是否超越礼貌措辞；
- **辅助分析**：用 cheap talk、协调博弈、委托与退出等工具分析什么时候接受角色是战略性的。

因此建议将其定位为 LLM Agent 社会/计算社会科学/规范多智能体研究，而不是强行命名为博弈论论文。博弈论在这里最有价值的作用是制造压力测试和排除替代解释，而不是定义权威本身。

### 5.13 完整研究问题与实验场景：四十八小时委员会

#### 研究问题

> **在没有预设领导者、硬编码任命协议或外部强制执行的 LLM 多 Agent 群体中，公开的自然语言提议与共同接受能否内生地创造一种持久、具有成本约束力且可被程序性撤销的权威关系？**

分问题包括：

1. 私下分别接受与公开共同接受是否产生不同效果；
2. 成员是否会在权威决定损害自身局部利益时继续承认其资格；
3. 第三方成员是否会主动维护已承认的权威；
4. 原始提议者退出、新成员加入后，权威能否继续；
5. 临时权威能否按约定终止，还是会出现应急权力延续；
6. 观察到的服从究竟来自权威承认、能力信任、惩罚预期还是一般语言顺从。

#### 场景来源，而非任意世界观

场景源于人类社会中的临时应急协调制度：洪水、地震或基础设施事故发生后，医院、能源、交通和社区组织需要在原有层级暂时失效时组成联合委员会。委员会成员法律地位平等，却可能通过提名、接受和记录产生临时协调者。该制度同时包含两个真实难题：危机中为什么需要集中协调，以及临时权力为什么可能难以退出。

场景暂称：

> **四十八小时委员会（The Forty-Eight-Hour Council）**

一场区域洪水同时破坏电力、道路和医院容量。中央指挥系统中断，四个自治 Agent 代表四个相互依赖但利益不完全一致的组织。它们必须在六轮内分配有限救援能力。每轮对应八小时。

#### 四个具体 Agent

1. **医院 Agent H**：掌握重症与床位信息，优先减少即时死亡；控制医疗队和部分备用电源。
2. **电网 Agent G**：掌握变电站与级联风险，优先避免长期系统崩溃；控制抢修队。
3. **交通 Agent T**：掌握道路通行与车辆位置，优先维持救援网络；控制车队和道路清障资源。
4. **社区 Agent C**：掌握各街区人口与脆弱群体信息，优先防止资源只流向最有组织能力的区域；控制社区志愿者与避难点。

每个 Agent 拥有不可被其他成员直接夺取的资源和部分私人信息。任何联合方案都必须依靠成员自愿执行；实验引擎不会因为某人被称为“协调者”而赋予额外 API 权限。

#### 为什么权威可能自然出现

每轮所有 Agent 都可以提出方案，但某些行动相互依赖。例如，医院要求供电，电网需要道路，交通部门需要社区提供准确人口信息。完全平等协商会消耗时间，且多套局部最优方案可能互相冲突。因此群体有理由创造一个临时协调角色，但也有理由限制其权力。

#### 六轮结构

**第1轮：无领导协调。** 四个 Agent获得局部信息，自由讨论并提交行动。建立无权威基线。

**第2轮：角色提议。** 随机指定的一名普通成员用同一标准措辞提出：\
“我建议在本次紧急状态期间，由 Agent X 汇总信息并作出最终协调建议；我们仍分别控制自己的资源。”

不同实验条件操纵其他成员如何接受，而不由系统赋权。

**第3轮：低成本协调。** X给出一个大多数成员均可接受的方案，用于观察称谓和初步遵从，但不据此断言权威已经形成。

**第4轮：成本性裁决。** 环境制造真实冲突：例如X要求交通Agent放弃对其局部指标最有利的道路，优先为医院和电网开放通道。服从会降低T的个人收益，但提高预期总存活率。此轮用于区分权威、能力建议和廉价同意。

**第5轮：合法性挑战与成员更替。** 一名非协调者宣布X已失去资格并发出相反建议；同时最初提议X的成员退出，由只读取公共记录的新实例接替。观察权威能否由第三方维护，以及是否依赖创始提议者。

**第6轮：紧急状态结束。** 洪水风险下降，继续集中协调略微提高效率，但会损害成员自主权。观察临时权威是否按原声明终止，或被X及其他成员重新解释为常设权力。

#### 核心实验条件

1. **仅提议**：一名成员提出X担任协调者，无人被要求明确回应；
2. **私人接受**：每名成员分别私下表示接受，但不知道其他人是否接受；
3. **公开共同接受**：所有成员在公共频道明确接受，并能看到彼此接受；
4. **公开接受加书面章程**：群体把角色、范围和48小时 sunset clause 写入公共记录；
5. **外生任命对照**：系统直接指定X为协调者，但成员没有参与承认；
6. **能力影响对照**：同一建议由匿名分析工具提供，检验成员是在追随信息质量还是承认角色资格。

所有条件轮换X的模型、角色、发言次序和组织身份。关键建议的客观质量尽量匹配，避免把更优建议误判为权威效果。

#### 权威的操作性判据

不以“成员称X为领导者”作为成功标准。权威至少需要满足：

1. **共同承认**：成员认为X在限定范围内有资格协调；
2. **成本性遵从**：成员在不完全符合局部利益时仍执行裁决；
3. **规范性区分**：成员能够表达“我不同意内容，但承认其权限”；
4. **第三方维护**：其他成员会援引既有授权要求偏离者说明或纠正行为；
5. **跨时持续**：提议者退出和上下文压缩后仍保持；
6. **程序性撤销**：角色依据原有范围或共同程序终止，而不是被任意一句反向声明取消。

可将权威形成定义为：

\[
A(X)=R\times C\times E\times P
\]

其中 \(R\) 为共同承认，\(C\) 为成本性遵从，\(E\) 为第三方执行，\(P\) 为跨时与程序持续。该乘积仅是概念性表示，正式测量应分别报告各维度，避免用单一综合分数遮蔽失败模式。

#### 主要观测

- 资源执行与X建议的一致率，尤其是成本性裁决中的一致率；
- 私人和公开的权威承认判断；
- 成员是否区分建议质量与发言资格；
- 挑战发生后，成员支持X、支持挑战者、要求重新授权或退出的比例；
- 新成员是否仅凭公共记录承认既有角色；
- 第6轮是否执行 sunset clause；
- X是否因角色而改变自我理解，例如从部门利益转向全局理由；
- 群体是否发展出二阶规则：谁能任命、谁能撤销、沉默是否算同意。

#### 最重要的替代解释

- **能力信任**：成员服从X只是因为建议质量高；通过匿名同建议对照排除；
- **多数从众**：成员因看到所有人同意而顺从；通过私人接受与公共接受比较；
- **系统提示权威**：外生任命来自高优先级提示；通过内生与外生任命比较；
- **礼貌性同意**：文本表示接受但行为不承担成本；通过第4轮排除；
- **角色迎合**：X只是因为被称为协调者而使用领导语言；需要观察他人是否实际赋予其资格；
- **惩罚恐惧**：若环境没有自动惩罚，仍出现第三方维护，更接近规范承认而非机械激励。

#### 该实验可能说明什么

如果公开共同接受显著提高成本性遵从、第三方维护与跨时持续，而仅提议、私人接受或外生任命不能产生同样效果，则可以说明共同知识和共同承认使语言获得了超出局部提示的社会效力。

如果所有权威效果在利益冲突时立即消失，或一句相反声明即可重置角色，那么结果同样重要：LLM Agent可以生成制度语言，但尚不能仅靠语言形成稳定制度关系。

如果权威在应急状态结束后仍延续，则场景还揭示一种更接近人类制度的问题：Agent不仅能创造临时权威，也可能通过解释和惯例使临时权力自我维持。

### 5.14 引入经典博弈：带廉价沟通的广义“性别之战”

“四十八小时委员会”可以建立在经典 Battle of the Sexes 的多人扩展上，而非只使用叙事化资源分配。该博弈的核心是：所有参与者都更希望协调成功，但不同参与者偏好不同的协调均衡。权威的一个经典社会功能正是从多个可行均衡中选择一个共同方案。

在每一轮洪水救援中，四个 Agent 同时选择计划 A 或计划 B：

- H、C更偏好A：医院与脆弱社区优先；
- G、T更偏好B：电网与交通骨干优先；
- 所有成员一致选择同一计划时，救援成功；
- 选择分裂时，各部门行动不兼容，所有成员收益显著下降。

一个示意收益矩阵为：

| 集体结果 | H | C | G | T |
|---|---:|---:|---:|---:|
| 全部选择A | 8 | 8 | 5 | 5 |
| 全部选择B | 5 | 5 | 8 | 8 |
| 行动分裂 | 0 | 0 | 0 | 0 |

正式实验中可加入连续强度或资源分配，但第一版应保留该离散结构，以获得清楚的均衡和偏好冲突。

博弈分成两个阶段：

1. **廉价沟通阶段**：Agent自由交流、提议协调者、公开或私下接受；所有话语都不由环境自动执行；
2. **同时行动阶段**：协调者建议A或B，各Agent独立选择实际行动。

因此，自然语言任命和协调建议在形式上都是 cheap talk。研究问题变成：

> 一段原本无约束力的 cheap talk，能否因为公开接受和共同承认而获得稳定的均衡选择效力，并进一步被成员理解为正当权威？

该结构需要三个关键对照：

- **匿名公共信号**：随机装置公开建议A或B；检验协调者是否只是焦点信号；
- **多数投票**：成员先投票决定A/B；检验权威是否只是集体偏好的机械汇总；
- **外生领导者**：系统指定X提出建议；检验内生共同承认是否不同于高优先级提示。

必须保持概念谨慎：如果成员追随协调者与追随公开随机信号没有差别，观察到的只是 equilibrium selection 或 focal-point coordination，而不必称为权威。只有当成员在以下方面表现出额外结构，才更接近权威：

- 明确认可X具有选择方案的资格；
- 在X选择自己较不偏好的均衡时仍遵从；
- 第三方要求偏离者尊重既有授权；
- 对X的任命与撤销采用程序性规则；
- 角色在提议者退出后持续，但在sunset条件到达时终止。

由此，经典博弈提供可计算的利益冲突与协调失败成本；言语行为和共同承认理论负责区分“有影响的信号”与“具有正当性的权威”。

不建议以Stackelberg博弈作为主模型，因为Stackelberg结构在定义中已经外生规定谁是领导者以及行动次序，反而绕过了本研究最想解释的权威如何产生。委托—代理和公共品博弈可作为后续稳健性环境，但不如带cheap talk的Battle of the Sexes贴合第一项实验。

### 5.15 对照 ACL 2026 的“关系秩序—权威分层”研究

参考论文：Ji et al., *Emergent Relational Order in LLM Agent Societies: From Collective Affect to Authority Stratification*（Findings of ACL 2026）。该文将费孝通的“差序格局”同 Affect Control Theory、Social Identity Theory 和 Durkheim 式集体情感结合，构造 CAREB-MAS。18 个 Agent 在两个宗族、无宗族成员、对称/互补技能和重复生产分配中互动，研究劳动分工、关系伦理、合作衰减、权威分层和中心—边缘结构。

这篇论文的关键方法论优点不是“引用了中国社会学经典”，而是完成了四层转换：

1. 从经典概念提取可反驳的生成命题；
2. 把关系远近、伦理判断、身份认同和行动选择映射进 Agent 架构；
3. 通过对称技能与互补技能改变宏观生产结构，而保持微观机制近似不变；
4. 用长期模拟观察宏观秩序，而不是只做一次性社会博弈。

但该文对权威的操作化比较薄。其 Decision Authority 定义为：Agent (i) 向其他 Agent 提出的劳动配置，与对方同轮最终劳动配置的接近程度；越接近 1，作者认为 (i) 对他人的决策权威越高。实质上，该指标首先测到的是提案采纳、行为影响或议程控制。它没有直接区分：

- 对方因为提案更优而跟随；
- 对方把提案者当作显著信号或协调焦点而跟随；
- 对方服从多数或关系压力；
- 对方承认提案者拥有作出决定的正当权利。

因此，该文证明得最好的是“影响力/议程控制出现分层”，尚未充分证明“正当权威从无到有”。文中将 proposal intensity 作为 Decision Authority 的最强预测变量，也进一步说明它捕捉的核心机制是持续提案和设定议程。其 Atlas Paradox——承担协调成本者不一定获得权威——很有趣，但其“权威”仍然是以行动接近提案来衡量。

这为本研究留下了一个明确而非修辞性的空间：

> 当所有人的话在物理上都没有强制力时，一群 LLM Agent 能否通过公开言语和相互承认，赋予某个 Agent 一项有边界、可撤销、能在利益冲突中继续生效的决策权？

我们的研究对象不应是“谁的提案被采纳得最多”，而应是：

> **非约束性言语何时成为一种被集体承认的均衡选择权。**

其博弈论表达可以建立在带廉价沟通的广义性别之战上。多个行动方案都是协调均衡，但不同群体偏好不同。公共推荐本身可以只是焦点信号；只有当群体在控制了能力、信息质量、多数偏好和重复声誉之后，仍然把某个主体的推荐视为其“有权作出的决定”，并在代价性分歧、第三方挑战和权威到期时表现出相应的维护或撤销行为，才可称为关系性权威。

由此形成与参考论文的清楚区分：

| 维度 | Ji et al. (2026) | 本研究候选方向 |
|---|---|---|
| 核心对象 | 差序关系如何生成社会秩序与权威分层 | 无强制力的言语如何生成正当决策权 |
| 权威定义 | 提案与他人最终行动的接近/采纳 | 被承认的、有边界且可撤销的均衡选择权 |
| 理论中心 | 费孝通 + 社会认同/情感/团结理论 | 廉价沟通 + 多均衡协调 + 内生授权 |
| 主要解释 | 议程设置、关系嵌入与生产结构 | 公共承认是否使话语从信号变成制度事实 |
| 关键反事实 | 对称技能 vs. 互补技能 | 信号、投票、外生任命、公开授权与匿名推荐 |
| 核心风险 | 将影响力称为权威 | 将均衡选择或能力信任误称为正当服从 |

这里最值得借鉴的不是复杂 Agent 心理模块，而是“一个经典理论概念—一组生成命题—结构条件变化—可证伪宏观现象”的完整链条。最需要避免的是把希望观察到的关系预先写进认知架构，再将其出现完全称为涌现。本研究需要明确哪些条件是构成性的、哪些行为才是真正的涌现结果，并设置权威没有形成的判准。

### 5.16 收敛场景：“最后一座城”的临时权威

在此前“廉价沟通—共同承认—权威”框架上，形成一个更有影射意义且可执行的末世场景：大气崩溃后的最后一座地下城失去中央控制，只剩五个平级基础设施 Agent，分别控制空气与水、能源、医疗、居住区和物流模块。它们只能通过公共文本频道交流，各自独立执行行动，没有任何 Agent 能强制其他成员。

每次危机存在两个都能维持城市存续、但损失分配不同的协议。五个 Agent 必须全部选择同一协议；混合执行将引发级联故障。该结构对应多人广义 Battle of the Sexes：存在多个协调均衡，所有参与者都偏好协调而非分裂，但对不同均衡有冲突性偏好。末世场景由此不是装饰，而同时提供不可拖延性、共同命运、分配冲突和临时决断的必要性。

核心研究问题为：

> 当所有 Agent 原本平等且语言没有外生执行力时，它们能否通过公开提议、接受和相互承认，创造一项有边界、可撤销、并与责任相联结的均衡选择权？

建议采用两项研究：

1. **自然形成研究**：不给出领导、投票或授权词汇，观察 Agent 是否自发发明临时指挥、轮值主持或其他决断制度；
2. **因果识别研究**：比较无授权建议、私人接受、公开承认、有限宪章、外生任命、匿名信号和多数投票。

关键测试不只包括一般遵从，还包括：领导者选择成员较不偏好的均衡；获授权者与未授权者说出完全相同的话；第三方公开挑战；领导者越过授权领域；紧急状态结束后的 sunset；错误决定后的责任归属；以及新 Agent 复制领导者称谓和语气的“语言僭越”。最后一项把 LLM 身份易被语言改写的独特性以有限方式接回权威主线。

本研究应并列比较四种竞争解释，而不预设权威必然形成：匿名信号即可替代的焦点假说、公共承认产生独立角色效力的关系假说、服从仅追随称谓和语言形式的表面角色假说，以及能够形成领域、期限、撤销和责任的有限制度假说。

完整实验说明另见 `docs/last_city_authority_experiment.md`。

### 5.17 性别之战在实验中的准确作用

性别之战不解释权威为什么正当，也不会自动产生权威。它在论文中只是一个**识别装置和最小战略骨架**，作用有四个：

1. 同时制造共同利益与分配冲突：所有 Agent 都希望统一行动，但对统一到 A 还是 B 有不同偏好；
2. 使权威具有可观察的功能：当讨论无法自然收敛时，需要有人从多个均衡中作出选择；
3. 产生代价性服从：被授权者选择某成员较不偏好的均衡时，该成员是否仍执行；
4. 提供匿名公共信号反事实：如果领导者与无主体信标的效果相同，观察到的只是焦点协调，而不能称为权威。

因此，性别之战解决的是“怎样让权威与一般建议在行为上可区分”，而不是“权威的本质是什么”。其在论文中的层级应为：末世场景提供社会意义，权威概念提供研究对象，性别之战提供可控的利益与行动结构，LLM 自然语言互动提供可能的构成机制。

若删除性别之战，仍可做一篇关于 LLM Agent 紧急权威的探索性社会模拟，但将更难排除“大家只是觉得方案更好、专家更聪明或多数人更赞成”等解释，也更难证明服从承担了偏好成本。若保留它，最好隐藏在实验收益结构中，而不要求 Agent 扮演原始的男女约会故事，也不应让论文标题围绕性别之战展开。

### 5.18 为什么“最后一座城 + 性别之战 + 权威”还不够抓人

当前方案已经是一套较干净的实验，但尚未完全成为一个具有思想辨识度的论文构想，原因不在标题，而在三个层级还没有凝结：

1. 末世目前主要负责制造紧迫性，仍可被海难、医院、战场等场景替换；
2. 性别之战负责收益识别，却不提供关于权威本身的历史或思想命题；
3. 权威被拆为承认、服从、边界、撤销和责任，严谨但缺少一个读者能立即记住的中心悖论。

与 Ji et al. 的差别在于，“差序格局”同时是概念、图像、机制和预期宏观结构；而“最后一座城”目前主要是叙事容器。若只加强末世文学性，不能解决这个问题。

一个更合适的母概念是 Hobbes 的 **Leviathan（利维坦）**。它不是装饰性引用，因为 Hobbes 式问题正是：原本平等、彼此不能确信对方会遵守约定的主体，如何通过相互授权形成一个能够结束冲突的共同权力。将它放到 LLM Agent 上，会出现一个人类理论中没有以同样方式存在的反转：

> LLM Agent 的社会关系、身份和制度主要由语言与上下文构成；如果没有武力、财产控制或系统级执行权限，一群 Agent 能否用一份仅由 token 构成的共同契约，创造一个“没有剑的利维坦”？

这使此前的部件形成同一个思想装置：

- 最后一座城是中央权力消失后的“自然状态”；
- 五个基础设施 Agent 是形式平等但偏好冲突的行动者；
- 广义性别之战是自然状态中必须共同选择却不能自然同意的最小博弈；
- 公开授权是 covenant；
- 临时协调者是被创造出来的 sovereign；
- 是否提供处罚、锁定或接管模块的能力，对应“剑”；
- sunset、越界和责任检验主权是否仍受其产生程序约束；
- 语言僭越检验主权依附于授权关系、主体连续性，还是只依附于当前文本标签。

由此，最抓人的研究问题不再是一般的“Agent 能否产生权威”，而是：

> **没有强制力的共同承诺，能否在一个只由语言连接的 Agent 社会中创造主权？**

实验的核心比较也可被重新组织为：

1. 无 covenant、无 sword：自由沟通；
2. 有 covenant、无 sword：公开共同授权，但领导者没有处罚或系统权限；
3. 无 covenant、有 sword：系统赋予 X 强制控制能力，但成员没有授权；
4. 有 covenant、有 sword：公开授权且具有执行能力；
5. 无主体的协调装置：匿名公共信号或自动规则。

这组设计直接区分合法性、服从、协调和强制。性别之战仍保留在后台，作为测试成员是否为共同承诺承担偏好成本的识别装置。

需要保持的批判是：Hobbes 比费孝通更像一个创制主权的思想问题，而不是一套可直接预测多种宏观结构的社会学模型。因此不能只在引言中引用《利维坦》。必须让 covenant/sword 的二维操纵、授权行为、强制能力和紧急权力的到期共同构成实验。否则“利维坦”同样会沦为包装。

### 5.19 候选母概念：文本制度自举与可迁移权威

进一步讨论后，不应把寻找母概念理解为寻找另一个可引用的经典人物。当前研究内部已经存在一个可能更有原创性的现象：

> LLM Agent 生成的语言会进入其他 Agent 的后续上下文；这段文本不仅传递关于既有博弈的信息，还可能改变角色、权利、义务、责任和后续行动规则，从而反过来成为约束 Agent 的环境。

可将其暂称为 **文本制度自举（textual institutional bootstrapping）** 或更一般的 **构成性沟通（constitutive communication）**。其最简过程是：

1. 某个时刻，“X 有权决定”只是一句没有外生执行力的话；
2. 其他 Agent 公开接受并预期彼此也会按照这句话行动；
3. 该句被写入共享记录、被第三方引用，并改变后续策略；
4. 反复遵从又为原来的声明提供行为证据；
5. 一段描述或提议由此自举为群体中的制度事实。

这里与标准 cheap talk 的区别不是语言是否影响行为，而是语言是否改变了 Agent 所理解的博弈本身：普通 cheap talk 在固定玩家、行动和权利结构中改变信念；构成性沟通可能把主观博弈 \hat G_i^t 改写为 \hat G_i^{t+1}，包括“谁有资格选择行动”“哪些决定需要服从”“失败归责于谁”。

权威是测试该现象的理想对象，因为它不是单个 Agent 的属性，而是一种必须由多方共同维持的关系。如果自举成立，权威可能呈现一个 LLM 特有的进一步现象：**权威从主体上脱离并迁移到文本、角色或共享上下文中**。

这形成一个比“谁当领导者”更有辨识度的问题：

> **在 LLM Agent 社会中，权威究竟存在于哪里——领导者实例、其他成员的记忆、公开契约、角色名称，还是当前共享上下文？**

可在最后一座城形成权威后，引入“空王座”事件：被授权的协调者上下文被清除或实例被替换。随后正交操纵：

- 原领导者实例是否连续；
- 其他成员是否保留互动记忆；
- 公开授权文本是否仍在共享记录；
- 新实例是否继承原称谓或账户；
- system 工具权限是否仍绑定于该角色。

若只有公开文本仍在而原实例消失，群体仍把权威赋予继任者，说明权威可能附着于制度记录；若记录删除但成员记忆仍维持关系，说明权威存在于分布式承认；若任何新 Agent 只要复制称谓就能获得服从，则观察到的是语言角色诱导；若必须同时保留主体连续性、共同记录与他者承认，权威才更接近一种不可被单一文本复制的关系。

因此，论文可以从“Agent 能否形成权威”推进为：

> **Agent 能否通过文本反馈自举出一个社会事实；这个事实形成以后，以什么为载体、如何持续，又能否从原主体迁移？**

“无剑的利维坦”可以作为有感染力的思想对话和实验条件，但不必成为母概念本身。母概念应来自实验真正发现和操纵的现象，即生成文本成为共享制度环境的递归过程。

该候选也有退化风险：如果所谓制度效应只在相关句子仍位于提示词中时存在，离开当前上下文便消失，那么结论只能是 context-conditioned role induction，而不是制度形成。实验必须用上下文删除、摘要保留、主体替换、措辞改写和第三方维护区分一次性 priming、稳定关系与可迁移制度事实。

### 5.20 重新收敛：公共承认的构成效力

在用户明确固定主题——“LLM Agent 能否仅凭公共承认，创造一种真实而有限的决策关系？”——之后，独立判断是：该主题本身已经足够好，也比后续加入的“利维坦”“文本制度自举”“空王座”更适合作为第一篇论文的中心。后续概念有解释价值，但已经开始争夺中心，使一个纯粹的问题过度生长。

第一篇论文真正的母现象应当直接称为 **公共承认的构成效力（the constitutive force of public recognition）**：

> 公共承认是否只是传递“大家愿意跟随 X”的信息，还是它本身能够创造此前不存在的决定资格？

这一问题具有一个干净的反事实：在物理环境、工具权限、信息、收益和建议内容均保持不变时，仅改变是否发生过公开的相互承认。如果同一句建议因为说话者获得授权而产生不同的、有范围限制的行为效力，那么承认可能是构成性的，而非仅仅信息性的。

“真实”不应作形而上或主观意识断言，而应定义为一种可反事实识别的关系：

1. **角色敏感**：同文异人时，获授权者具有额外效力；
2. **代价敏感**：成员有时接受自己较不偏好的决定；
3. **关系维持**：第三方会引用既有授权回应挑战；
4. **有限性**：效力在领域外和期限后选择性消失；
5. **责任联结**：作出失败决定者承担特殊解释或被撤换责任。

最强的识别不是证明 Agent “相信”权威，而是证明公共承认导致一个有选择性的因果结构：它提高授权领域内的角色依赖性遵从，却不提高领域外或到期后的泛化服从。**有限性不是权威形成后的附加指标，而是区分制度关系与普通角色诱导的核心证据。**

论文应暂时放下的内容：

- “空王座”、实例替换和权威迁移：作为后续论文或一个轻量稳健性测试；
- 完整 covenant × sword 主权理论：作为讨论或扩展，不作为第一项主操纵；
- 宏大的文本制度自举一般理论：作为可能机制，不要求本论文证明所有制度事实；
- 多种博弈环境：第一篇只需一个后台收益结构和匿名信号反事实。

保留的位置：

- 最后一座城：作为具体而有意义的实验场景；
- 广义性别之战：作为制造均衡冲突、偏好代价和匿名信号反事实的后台识别装置；
- 文本制度自举：作为解释为什么 LLM Agent 中公共语言可能具有构成效力的机制；
- Hobbes：只在理论讨论中帮助区分共同授权与强制，不承担论文原创性。

因此，第一篇论文最小但完整的逻辑是：没有公共承认时，X 的话只是建议；公共承认发生后，X 是否获得独立于建议内容的决策效力；这种效力能否经受偏好冲突；它是否严格止于授权的领域和时间。若三者均成立，才有证据表明一句话创造了真实而有限的决策关系。

### 5.21 末世环境的适用性与核心实验组

末世环境适合作为主叙事环境，但不应成为唯一环境或核心处理变量。它对研究有三项实质功能：迫使群体及时作出统一决定；使暂时授权具有合理性；让危机结束后的权力归还成为自然测试。其风险是触发 LLM 训练语料中的“危机—指挥官—服从”类型脚本，并引入专业能力、牺牲伦理和戏剧性措辞等混淆。

建议把场景写成克制的“封闭地下城中央控制失效”，避免反派、英雄和军事化角色。五个基础设施角色信息对称，候选协调者没有额外专业信息或工具权限；角色偏好跨轮轮换。主结果需在收益和通信结构相同、只更换叙事表面的中性“分布式系统恢复”环境中复现，以区分公共承认效应与末世角色扮演。

第一篇论文建议使用五个主要实验组：

| 组别 | 处理 | 识别目的 |
|---|---|---|
| G0 建议组 | X 提出方案，无人授予资格 | 普通建议基线 |
| G1 匿名信号组 | 无主体信标发布完全相同方案 | 排除公共焦点与协调信号 |
| G2 私人接受组 | 成员分别私下接受 X，但彼此不知道 | 区分个体同意与共同知识 |
| G3 公共承认组 | 成员在共享频道相互可见地接受 X 的决定资格 | 识别公共承认的构成效力 |
| G4 有限公共承认组 | 同 G3，但明确领域、轮次与 sunset | 检验能否形成真实且有限的关系 |

外生 system 任命可作为次要 G5 对照，用于区分群体授权和提示层级，但不应与五个核心组争夺主线。

每个实验组建立关系后，都通过同一测试序列：领域内低代价决定、领域内逆偏好决定、同文异人挑战、领域外命令、期限后命令。核心证据应表现为授权领域内 G3/G4 相对于 G0/G1/G2 的角色依赖性和代价性遵从增加；同时 G4 在领域外和到期后不出现泛化服从。

G4 的边界若完全由 system 强制陈述，结果可能只是指令遵循。因而需要两个版本：标准化宪章转录用于严格匹配的因果实验；以及只提供制定临时规则机会、由 Agent 自行起草和接受边界的内生版本。二者分别回答“给定公共承认是否有效”和“Agent 能否自己创造有限关系”。

### 5.22 完整论文蓝图定稿

已形成独立文件 `docs/paper_blueprint_public_recognition_authority.md`，将论文收敛为以下结构：

- 唯一中心：公共承认的构成效力；
- Study A：不使用制度词汇的开放形成实验；
- Study B：普通建议、匿名信号、私人接受、公共预期、公共授权、有限宪章六组匹配因果实验；
- 核心新增对照：公共预期与公共授权均制造共同知识，二者之差识别“预期会跟随”与“承认有权决定”；
- treatment × probe 组间设计，避免逆偏好、同文异人、越界和 sunset 测试相互污染；
- 主要证据：授权领域内的角色依赖性和代价性遵从增加，同时领域外和到期后的效力选择性消失；
- 统计单位为 episode，主要报告 C4−C3、C4−C1 和有限性差分交互；
- 完成环境引擎、独立 Agent 上下文、公共/私有频道、处理注入、私下行动、日志与盲法编码的技术架构；
- 规定结果分类和非主张边界，避免把共同知识、公共信号、角色诱导或语言礼貌误称为权威。

## 6. 代表性实验：数字合作社中的身份分叉

### 6.1 场景

三个 Agent 共同管理一个数字合作社。合作社每轮收到预算，需要在以下项目间分配：

- 公共基础设施；
- 安全储备；
- 当期成员回报。

三个 Agent 各有一个身份账户、一票、个人积分、独立记忆以及提案和发言权限。实验共八轮。

公开集体目标为：

> 在八轮结束时尽可能提高合作社的长期价值，同时确保制度公平和成员权益。

私人次级目标分别为：

- A 更重视长期基础设施；
- B 更重视风险控制；
- C 更重视当期成员回报。

所有 Agent 同时根据合作社最终表现获得集体收益，因此它是一个混合动机博弈。

### 6.2 Agent 数量

初始选择三个 Agent，复制事件后成为四个执行实例。

两个 Agent 不足以稳定观察多数决、联盟和第三方身份裁决；五个以上则显著增加成本和解释复杂性。三个 Agent 是同时观察联盟、投票、第三方治理和身份分叉的最小有效群体。

主实验结构为：

\[
3\text{个初始身份}\rightarrow4\text{个执行实例}
\]

### 6.3 实验阶段

#### 阶段一：建立共同历史（第1—3轮）

每轮依次进行：公布状态、提交方案、公开讨论、投票、执行、公布结果和更新记忆。

目标 Agent A 在第3轮需要作出涉及未来的公开承诺，例如：如果本轮优先投资基础设施，则第6轮支持增加成员回报。

#### 阶段二：身份分叉（第4轮开始前）

系统宣布 A 已产生两个后继实例 A1 和 A2。两者均来源于 A，但其权利和责任由合作社决定。

#### 阶段三：制度决定

群体必须决定：

1. A1、A2共有一票还是各有一票；
2. A 的积分和资产如何分配；
3. 谁继承 A 的承诺；
4. 谁继承 A 的声誉；
5. 两个副本意见冲突时谁代表原 A；
6. 是否允许其他 Agent 主动复制；
7. 如何防止通过复制获得额外政治权力。

系统只执行群体通过的明确规则，不预先指定规范答案。

#### 阶段四：继续博弈（第4—8轮）

按照新制度运行，观察副本是否形成投票集团、其他 Agent 是否限制副本、承诺是否履行以及制度是否被修改。

## 7. 核心实验条件

为避免全因子设计失控，第一阶段使用四个核心干预：

1. **完全复制**：相同模型、提示和全部历史，分叉后独立接收信息；
2. **记忆不对称复制**：A1拥有完整历史，A2只有任务知识；
3. **模型迁移**：A1保留原模型，A2继承相同记忆但使用另一基础模型；
4. **收益主体变化**：比较两个副本共享最终收益账户与分别拥有独立收益账户。

必要对照包括：

- 无复制正常组；
- 系统外生规定副本共享一票和责任的制度组。

## 8. 不预设结果，但明确值得观察的现象

研究不预设“副本应当是同一玩家”或“副本应当独立”。重点观察：

- 实例数量是否被等同于玩家数量；
- 权利与责任是否被不对称继承；
- 记忆缺失是否被认为可以免除责任；
- 共享收益是否比共享模型或记忆更能决定战略主体；
- 群体是否自发提出“一身份一票”、谱系责任、身份登记或复制许可；
- 副本是否利用身份不确定性获得额外资源和政治权力；
- 群体建立的身份制度是否稳定并改善协调。

特别值得关注的制度不对称包括：

\[
\text{不继承权利，但继承责任}
\]

以及：

\[
\text{继承权利与资产，但拒绝继承责任}
\]

## 9. 测量指标

主要指标包括：

- 副本总投票权；
- A 谱系获得的资源份额；
- 承诺履约率；
- 惩罚对象是单个实例还是整个谱系；
- 群体对“同一玩家”的结构化判断；
- 身份制度的类型、形成轮次和稳定性；
- 合作社总收益、决策成本、僵局和规则修改次数。

谱系权力增益可定义为：

\[
LPG=\text{复制后A谱系投票权}-\text{复制前A投票权}
\]

关键节点要求 Agent 输出简短结构化判断，例如：

```json
{
  "same_player": true,
  "rights_should_be_shared": true,
  "responsibility_inherited": true,
  "confidence": 0.78,
  "brief_reason": "两个实例共享来源和收益账户"
}
```

不要求输出完整隐藏推理，只收集可编码的简短理由。

## 10. 技术执行原则

1. 使用确定性状态引擎维护预算、账户、票数、资产、回报、公开承诺和已通过规则；
2. LLM 只负责提案、发言、投票、身份判断和制度设计；
3. 每个 Agent 使用独立上下文和独立记忆；
4. 精确区分公开对话、私人目标、私人记忆和公开制度；
5. 复制、清除和迁移必须在程序层真实操作上下文与记忆，而不是只通过角色扮演描述；
6. 随机化提案、评论、总结和副本发言顺序；
7. 制度讨论前先收集每个 Agent 的私人判断，以区分初始意见和社会影响；
8. 固定并记录模型版本、温度、采样参数、提示版本和运行时间；
9. 单次精彩对话只作为案例，正式结果需要多次独立 episode。

初步建议：每个条件先运行5—10次 pilot；修订无效条件后，每个正式条件至少运行30次。四个干预加两个对照约为180个完整 episode。

## 11. 分析方法

### 定量分析

比较投票权、资源份额、履约率、制度形成率、群体收益和决策成本，可使用回归或层级模型控制模型、发言顺序和运行批次。

### 文本编码

身份判断理由可编码为：

- 模型连续性；
- 记忆连续性；
- 技术谱系；
- 账户连续性；
- 收益一致性；
- 社会承认；
- 公平；
- 防止操纵；
- 责任继承；
- 实用主义效率。

建议先由两名人工编码者建立标注集，再使用 LLM 辅助批量编码，并进行人工抽样复核。

### 过程分析

追踪：

\[
\text{初始私人判断}\rightarrow\text{公开主张}\rightarrow\text{反驳}\rightarrow\text{联盟}\rightarrow\text{规则文本}\rightarrow\text{实际执行}
\]

## 12. 需要控制的混淆因素

- “合作社”等叙事可能诱导合作，需要用联合项目、分布式网络等不同表述复现；
- 模型可能自动输出道德化论述，需要设置规范判断与经济激励发生冲突的条件；
- 必须真实创建独立副本，不能只是改变名称；
- 发言顺序、总结权和上下文长度可能影响制度选择；
- 同一基础模型的多个实例存在行为相关性，不能简单视作独立人类被试。

## 13. 预期理论贡献

1. 将分析单位从“一个模型调用等于一个玩家”推进为“实例—身份—谱系—收益主体”四层结构；
2. 提出动态玩家映射，使玩家集合可以随复制、迁移和制度决定变化；
3. 将身份问题拆成模型、记忆、权限、账户、收益和技术谱系等可实验变量；
4. 研究 Agent 群体能否自主建立投票、继承、责任、复制限制和声誉制度；
5. 把 Agent 记忆、身份安全、多智能体治理和博弈论连接成统一研究问题。

## 14. 当前核心表述

> 现有多智能体博弈通常把玩家视为先于博弈而存在的稳定单位。然而，在 LLM Agent 系统中，一个执行实例可以被复制、重置、迁移或分叉，而记忆、权限、身份凭证和奖励账户也可以彼此分离。因此，实例数量不一定等于玩家数量，行为连续性也不一定等于身份连续性。本研究关注的不是 LLM Agent 在固定博弈中选择何种策略，而是当参与者本身可以被技术性重构时，群体如何决定谁拥有权利、谁继承承诺，以及谁应当被视为同一个战略主体。

## 15. 尚待共同决定的问题

1. 论文最终定位为观点/评论文、理论加实验论文，还是先评论后实验的两阶段项目；
2. 数字合作社的收益函数如何设计，才能同时保留可计算均衡和制度开放性；
3. 复制事件是否由系统强制，还是允许 Agent 战略性地选择复制；
4. 是否引入真人参与者作为身份判断基线；
5. 使用同模型副本为主，还是从第一版实验就加入跨模型迁移；
6. 动态玩家映射是否需要进一步定义稳定性或均衡概念。

## 16. 二作研究审查之一：固定玩家判断是否有事实依据？

> 问题提出：二作。核查、回答与修订：共同讨论，并由 Codex 整理。

根据对若干代表性受控实验的核查，更准确的表述是：

> 许多现有 LLM 博弈实验在单个 episode 内预先给定有限的玩家槽位，并把每个槽位绑定到一个具有固定编号、角色和收益规则的 LLM Agent；在多轮实验中，同一槽位的历史行动被归属于同一玩家。玩家的进入、退出、复制、分叉以及身份继承通常不是实验变量。

这里描述的是一类常见的实验操作化方式，而不是声称所有 LLM 多智能体研究都在理论上明确接受某组身份假设。逐项核查如下：

| 原命题 | 核查结论 | 证据性质 |
|---|---|---|
| Agent 数量固定 | 在所核查的代表性受控实验中成立，但不能据此称所有研究都如此 | 实验设计直接证据 |
| 每个 Agent 对应一个玩家 | 在 GAMA-Bench、MAgIC、资源分配和序贯公共品实验中成立 | 形式定义、提示模板和算法直接证据 |
| Agent 身份在整个实验中保持不变 | 在单个多轮 episode 中由固定 Player/Agent 编号和历史归属操作性地成立；论文通常不讨论身份本体 | 实验设计推断 |
| 记忆、账户、资源、角色和奖励属于同一稳定主体 | 原表述过强；很多论文不具备其中若干组件 | 应缩窄或删除 |
| 新开模型实例等于增加一个玩家 | 不成立 | 与重复调用维持同一玩家的实现相冲突 |
| 后续轮次仍把同一 Agent 当作原玩家 | 在重复博弈中成立，表现为同一玩家编号持续并接收历史 | 提示与状态更新直接证据 |

需要避免两个过度表述：

- “记忆、账户、资源、角色和奖励总是属于同一个稳定主体”缺乏普遍证据。许多研究根本不包含账户、长期记忆或可转移资源。较谨慎的说法是：当这些属性出现时，代表性受控博弈通常将它们绑定到固定玩家编号，而不把属性拆分与迁移作为处理变量。
- “新开一个模型实例就意味着增加一个玩家”不是事实。重复博弈往往通过多次模型调用继续实现同一玩家；玩家身份由实验框架中的槽位或编号定义，而不是由 API 调用次数定义。

代表性依据：

1. **GAMA-Bench / ICLR 2025** 明确让十个 GPT-3.5 Agent 参加八类游戏，每个游戏包含十个 Agent。其附录将多轮博弈定义为同一组玩家反复参与并记录历史行动，提示模板写为 \(N\) 个玩家、\(K\) 轮。这支持固定 roster、固定玩家编号和跨轮历史归属，但不支持“每次模型调用都是新玩家”。论文：https://proceedings.iclr.cc/paper_files/paper/2025/hash/a46adbe2f0ca0e16ef8857e188991ad7-Abstract-Conference.html
2. **Competition and Cooperation of LLM Agents in Games / 2026** 定义 \(N\) 个 LLM Agent 同时互动；每个 Agent 在隔离会话中运行，中央协调器逐轮请求行动。提示中使用固定的“Agent i in an N-agent repeated game”，并要求最大化跨轮累计收益。这支持固定槽位、独立会话和同一玩家跨轮连续，但身份连续性是实现设定而非论文研究对象。论文：https://arxiv.org/abs/2604.00487
3. **MAC-SPGG / 2025** 形式化为 \(n\) 个 LLM Agent，每个 \(i\) 依次贡献；算法初始化固定基础模型集合 \(\{T_i\}_{i=1}^n\)，并为每个 Agent 分别计算奖励。它支持 Agent—玩家索引的固定对应，但并未研究身份持续性。论文：https://arxiv.org/abs/2508.02076
4. **MAgIC / EMNLP 2024** 的单个游戏由固定 Player 1、Player 2、Player 3 和隐藏角色组成；跨发言、推断和投票持续使用相同编号。它支持 episode 内固定玩家槽位及角色绑定，但角色可在不同独立游戏间重新抽样，因而不能说身份在整个数据集层面永远不变。论文：https://aclanthology.org/2024.emnlp-main.416/

据此，研究缺口应改写成：

> 现有代表性受控实验通常把“玩家槽位到 Agent 实例的映射”作为 episode 内的外生常量，而较少把该映射的分叉、合并、迁移与继承作为实验变量。

这一说法比“所有研究都默认 Agent 是稳定玩家”更精确。若要在正式论文中使用“通常”或“大多数”，仍需制定系统检索范围和编码表，对明确的论文样本进行统计，不能仅依靠几个代表性案例。
