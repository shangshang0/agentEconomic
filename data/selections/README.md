# Public data selection

`public-data-v1.jsonl` is the immutable allowlist for the first public data
release. It contains exactly 20 complete worlds: eight registered Stage 1
confirmatory worlds and twelve registered mechanism-ablation worlds.

Exploratory, contaminated, technically failed, legacy, operator-history, and
other reference assets are intentionally excluded from GitHub. Those assets
remain in the separately controlled local custody archive when they retain
research, provenance, or incident-analysis value.
