# Agent 本体经济学地基：当前承诺与边界

这份说明用于防止把 Lean 辅助证明、案例运行规则或实验流程误称为新的经济学公理。它不增加定理或经验前提。

## 先区分“公理”与 Lean 假设

当前项目没有自定义 `axiom`、`sorry` 或 `admit`。这只说明证明没有调用作者自设的逻辑公理；**它不意味着项目已经找到一套经济学公理**。Lean 中大量结构体字段、定理参数和前提是局部模型限制，不能因形式化而升级为地基公理。

当前地基更准确地说是一个最小建模语法，而不是一组预测 agent 行为的公理。它目前只有三类原语；它们是定义接口，不是对现实规律的公理性断言：

1. **主体状态**：一个可追踪计算主体及其内部/可归属状态。
2. **条件响应**：给定主体实际接收的输入与可见机会，主体产生行动提议；其响应核是待分析对象，理论不预设其形状。
3. **制度化转移**：规则把提议映射到执行、生产/核验结果及下一状态；每个映射可单独给定或识别。

经济案例还需满足范围条件：某种主体可归属的稀缺资源、可执行机会或约束性权利/义务，确实改变可执行集合或后续状态。纯文本意向而无可执行后果，不足以构成本文识别的经济事件；这也是研究对象的界定，不是关于 agent 行为的公理。

有限概率分布的非负、归一是数学表示要求，不是关于 agent 的经验公理。账本闭合、死亡阈值、响应规律、生产规律、匿名性及规模运输都是具体模型限制；每一项必须单独注明来源，不得写进普遍地基。

## 地基本身可以推出什么

不加入行为规律时，地基只支持结构性结论：提议、执行、生产和资源后果必须分开记录；若账本和执行门已知，可计算可行路径、资源上界和制度结果；若响应/生产联合规律没有被限制，行动方向与跨主体联合概率不能被唯一预测。

这些结论是有限的，但不循环：结论不把“agent 理性选择”“偏好稳定”或待解释的行为写进定义。对选择方向保持不识别，不是预测失败，而是当前地基拒绝伪造点预测。

## 什么才有资格成为新的理论规律

新增结果只有同时满足以下标准，才作为 agent 本体经济学规律，而不只是数学工具或案例实现：

- 前提来自上述构成、某个可独立说明的计算/制度机制，或明确可观测的案例限制；
- 结论不是定义、账本恒等式或对前提的重述；
- 结论收窄了此前允许的结果集合，给出非平凡、可观察的定量或比较静态预测；
- 前提若为经验限制，存在短小可复跑的核验与明确拒绝条件；否则不作为该案例预测前提；
- 形式证明、实现映射和经验检验分别报告，不相互替代。

通用概率界可以帮助从有限数据计算识别集合，但不因此成为 agent 经济学的新公理或新发现。实验准入规程在 [`EXPERIMENTAL_MODEL_ADMISSION.md`](EXPERIMENTAL_MODEL_ADMISSION.md)；通用数学证明工具在 [`lean/METHODS_INDEX.md`](lean/METHODS_INDEX.md)；理论与案例形式化结果在 [`lean/THEORY_INDEX.md`](lean/THEORY_INDEX.md)。
