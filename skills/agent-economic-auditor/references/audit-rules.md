# Audit rules

A complete analysis-eligible world must have a terminal `complete` registry
record, no active marker, no runner/watchdog process, zero Compose resources,
a final evidence archive, matching state/event sequence, frozen configuration
and runtime hashes, and only committed/reconciled recovery amendments.

The catalog is the executable inclusion gate. `reference` rows must have
`analysis_eligible=false`. Mechanism ablations do not add confirmatory sample
size. Discovery worlds motivate hypotheses but do not test the registered
claim.

Registered analysis uses world-level dots and provider-blocked pairings.
Required outputs include all dots, registered exact permutation inference,
bootstrap interval, leave-one-world-out, provider strata, and any frozen
leave-recovered-worlds-out or incident sensitivity. Do not add worlds or
choose exclusions after inspecting direction.

Dialogue is trace evidence. Cite its public redacted source and line/event
sequence. Do not infer an unregistered semantic rate by hand, and do not use
message-level pseudo-replication.
